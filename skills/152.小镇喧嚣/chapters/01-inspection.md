# Chapter 1: 迎检，迎检

## Core Idea
迎检不是对日常工作的中性检查，而是一套把乡镇整体卷入其中的**政治生产机制**。上级用“中心工作”“一票否决”和百分制考核，把常规行政临时改造成一场运动；乡镇则用动员大会、挂村干部、材料补做、群众工作与“氛围营造”把压力继续下传。检查所看到的“事实”，很大程度上是迎检过程本身生产出来的。

## Frameworks Introduced

- **压力型体制 + 动员型政治** — 压力型体制通过指标、排名、责任状向下加压；当任务时间紧、风险高、常规科层运作来不及完成时，乡镇会重新启用运动式治理：开大会、立军令状、全体下村、连夜返工。二者不是替代关系，而是相互嵌套。
- **迎检生产链** — 一次迎检通常包含：解读评分细则 → 分解指标 → 补做档案与签字 → 清退与票据回收 → 统一口径与群众演练 → 氛围布置（横幅、宣传车、打扫、疏散打牌） → 领导暗访应对。每一步都在制造可被检查的“痕迹”。
- **挂村干部制** — 乡镇干部“挂”到村，名义是协助，实际是把行政压力传递到村庄。没有挂村干部，压力型体制很难穿透已经原子化的村组。
- **一票否决与风险规避** — 只要触发关键事项，全部工作归零。于是基层的第一目标不是“做好”，而是“不出事”“不被否决”。

## Key Concepts

- **中心工作** — 在特定时段压过一切常规工作的政治任务。
- **迎检** — 为上级考核评估做准备的全套组织行为。
- **一票否决** — 某项关键指标不合格即整体不合格。
- **七查七看** — 税改考核的七类检查内容，覆盖到户、到村、到乡镇。
- **挂村干部** — 乡镇派驻村级的干部，承担连带责任。
- **结算清退** — 把超收的税费退还给农户，并收回旧票据。
- **负担卡 / 公示牌** — 用于证明政策到户的文本装置。
- **痕迹管理** — 以档案、签字、照片、票据证明工作已做。
- **运动化治理** — 用集中动员而非日常科层方式完成突击任务。

## Mental Models

- **Use 迎检 when** 你想解释为什么乡镇在某个时段突然停止常规服务、全体干部消失下村。
- **Use 挂村制 when** 你想追踪上级压力如何越过“乡政村治”的边界进入村庄。
- **Use 一票否决 when** 你看到基层宁愿造假、垫钱、反复返工，也不愿承担单点失败的风险。
- **Use 动员型政治 when** 任务具有时间紧、政治敏感、跨部门、无法按常规预算完成等特征。

## Anti-patterns

- 把迎检当成对真实治理绩效的测量。它测量的是**准备能力**和**风险控制能力**。
- 认为档案齐全就等于工作到位。档案往往是事后补做、统一口径的产物。
- 认为税费改革后基层已不再强制。强制并未消失，而是转化为垫税、缠磨、人情和连带责任。
- 把“减负”当成线性利好。检查、清退、材料、接待本身也在增加基层负担。

## Worked Example

税改迎检前，秦家畈村面临一个技术难题：往年学校代收的教育费附加，农户手里还留着收据；而检查要求农户家中不得出现“两税”之外的任何收费票据。镇挂村干部范维萍请村里协助把票据收上来，村干部却不肯先动，因为担心镇里事后不退款，让村集体兜底。老罗翻出旧账：当年江堤维修款先缴后取消，镇里不仅没退，林书记还请他们吃饭，最后又让他们多缴一万元“支持工作”。

村支书陈志华说得很直：“政府这次不答应给钱，我给他搞个鬼。”范维萍只好回去请示。得到“钱由政府给”的答复后，村干部才开会、分工、逐户收票据。随后镇上召开战前动员大会：宣读紧急通知、强调一票否决、要求当晚完成报表、全体挂村干部连夜下村复查；镇里和学校共拿出六十多万元用于清退，换“今后的平安”。一场检查就这样把镇、村、农户重新编排进同一条紧张的生产线。

## Key Takeaways

1. 迎检的核心不是“被检查”，而是“被组织起来生产可检查性”。
2. 压力型体制需要动员型政治来突破常规科层的时间与资源限制。
3. 挂村干部制是压力穿透村庄的关键传动装置。
4. 一票否决把行政任务转化为政治任务，放大了造假、垫钱和形式主义。
5. 迎检会制造新的利益分配：谁出钱、谁垫钱、谁承担连带责任，都是谈判内容。
6. 检查越强调“到户”，越依赖村干部和乡土关系来“做通工作”。
