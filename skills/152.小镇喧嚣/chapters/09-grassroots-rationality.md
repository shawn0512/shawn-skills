# Chapter 9: 基层的理性

## Core Idea
基层干部的许多决定，用市场经济、法律条文或公共服务规范去衡量似乎“不合理”，但用**政治理性**去衡量却高度合理：他们要回应上级考核、维护稳定、制造可见政绩、避免问责。石场关闭、诱民致富、扶强不扶弱，都是这种政治理性的产物。理解基层，不是判断它“对不对”，而是搞清楚它在什么约束下、按什么逻辑做选择。

## Frameworks Introduced

- **“这是一种政治行为”** — 当市场逻辑、法律逻辑与政治逻辑冲突时，政治逻辑优先：稳定、上级注意力、政绩、问责风险决定行动。
- **稳定压倒一切 / 不出事逻辑** — 只要可能引发上访、群体事件或恶性案件，政府宁愿花钱、让步、拖延，也不愿冒险强制。
- **政绩工程与注意力竞争** — 上级领导抓什么，下级就重点做什么；项目要可见、可汇报、可检查，哪怕经济上不划算。
- **风险社会化** — 政府发起的项目，失败成本往往由政府、村庄和干部承担，农民则以“不配合”或“闹”转移部分风险。
- **选择性扶持 / 扶强不扶弱** — 有限资源优先给容易出成绩的对象，因为政绩需要回报，弱村弱户的边际收益太低。

## Key Concepts

- **政治行为** — 以政治后果而非经济收益为主要考量的决策。
- **政治账 vs 经济账** — 林书记常说“不能只算经济账，还要算政治账”。
- **底线** — 全部关闭、不闹事、不上访、不死人。
- **开弓没有回头箭** — 一旦公开承诺关闭石场，就不能因业主反对而退让。
- **诱民致富** — 政府用好处和承诺诱导农民参与项目。
- **锦上添花** — 资源投向已经较强的村或项目。
- **花钱买平安** — 用补偿、救济或“点发”换取稳定。
- **注意力** — 上级领导关注什么，基层就优先处理什么。

## Mental Models

- **Use 政治行为 when** 一项决定在经济上不划算、法律上不严密，却能解释为稳定、政绩或上级要求。
- **Use 不出事逻辑 when** 政府宁愿让步、拖延或私下补偿，也不愿强制执法或激化矛盾。
- **Use 选择性扶持 when** 资源有限，决策者需要可见的、可汇报的成功案例。
- **Use 风险社会化 when** 政府发起项目，却让农民、村庄或干部承担失败成本。

## Anti-patterns

- 用纯粹的市场效率或法律正义评价基层决策。那会错过真正的决策变量。
- 以为政府会平均地帮助所有村。资源跟着政绩可见度走。
- 以为“保护环境”“可持续发展”等口号就是真实动机。口号是合法性话语，动机可能是土地升值、上级检查和政绩。
- 以为政府害怕上访就会无限让步。政府会在“花钱买平安”和“不开口子”之间计算。

## Worked Example

区里决定关闭老虎尾和茶山李一带的十八家采石场。官方理由是保护环境、治理污染、配合北扩东移开发；但干部私下承认，真正触发关闭的，是高校来看地时被破坏的山体吓走，土地卖不出去。关闭意味着业主几十万到上百万的投资变成废铁，而政府只愿意退还电力增容费、给少量搬迁补偿，不谈赔偿。

镇里先是“三个十”政策：十天宣传、十天自拆、十天强拆；后来同意延期半年，条件是业主签字承诺不再索赔，并把协议拿去公证。半年后期限到来，政府停电、封矿；业主接回电线继续生产，随后十七人、二十四人两次进京上访。政府派人拦截、接回、请吃饭、买返程票，但坚持“补偿没有”。杨宏军因私藏炸药被拘留，郭德银放出“同归于尽”的狠话。

林靖南在干部会上说得很清楚：这件事“不亏理”，因为贯彻中央可持续发展、区里开发方针、实践“三个代表”；“石头飞上天还是要落地，事情出在哪里最后还是要由哪里来解决”；不怕上访，但要防止出事。对业主的补偿要求，政府不退让；对可能的群体事件，则全力稳控。这就是典型的政治理性：**用政治合法性话语包装开发利益，用稳定底线控制冲突升级，用拖延和消耗代替正面解决**。

## Key Takeaways

1. 基层决策的第一变量往往不是效率或正义，而是政治后果。
2. “政治行为”意味着要在上级注意力、稳定风险和政绩可见度之间做平衡。
3. 政府发起的项目，风险往往社会化；农民和干部都可能成为成本承担者。
4. “扶强不扶弱”不是道德缺陷，而是资源稀缺和政绩考核下的组织理性。
5. 口号和合法性话语很重要，但不能替代对真实利益和权力关系的分析。
6. 理解基层理性，不等于认同它；而是先看清约束，再谈改进。
