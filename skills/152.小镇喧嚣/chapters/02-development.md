# Chapter 2: 不开发，政府怎么办？

## Core Idea
在城郊乡镇，开发不是单纯的经济增长手段，而是解决政府自身财政危机、维持运转和制造政绩的**政治生存方式**。政府因此从公共权力载体变成“权力—经济复合体”，亲自充当土地商人、谈判者和补偿规则的制定者。开发的政治学，就是政府、村庄、农民三方在土地收益上既合作又争夺的规则。

## Frameworks Introduced

- **开发的政治学** — 乡镇政府主导招商引资、征地、补偿和基础设施建设；开发商主要与政府打交道，村级组织退为助手；补偿标准由政府单方面确定，农民缺乏制度性谈判渠道。
- **政府—村庄—农民三方争利** — 政府得大头（规费、基建、运转、政绩），农民得中头（土地、青苗、附着物、安置补偿），村庄得小头（部分土地补偿、管理费）。三方都有“道理”，但规则制定权在政府。
- **土地财政/权力经营** — 政府把土地非农化收益用于填补工资缺口、偿还历史债务、投资园区基建，并把土地处置权转化为经营资源和权力优势。
- **“培育地主，引进资本家”** — 林书记的发展话术：扶持种田能手扩大经营规模，引进老板和资本发展民营经济；小农经营只能“混饱肚子”。

## Key Concepts

- **招商引资** — 以土地、税收优惠和基础设施吸引外来资本。
- **土地征用 / 占压** — 国家建设或地方开发对农地的永久或临时占用。
- **补偿标准** — 由政府按亩产值倍数、附着物清单等确定，而非市场谈判。
- **生地变熟地** — 政府先投入“三通一平”，把农地变成可施工的建设用地。
- **以园养园** — 用土地收益滚动投入园区基础设施。
- **税赋悬空** — 土地抛荒或农民不签字，导致税收任务落空。
- **三化** — 农业产业化、工业化、城镇化，是乡镇主职干部的标准发展叙事。
- **父母官 / 土皇帝** — 乡镇一把手对辖区资源和人事的实际支配感。

## Mental Models

- **Use 开发的政治学 when** 你看到乡镇政府绕过村集体，直接与开发商谈地价、签协议、定补偿。
- **Use 三方争利 when** 分析征地冲突中“谁有理”的争论：各方都有局部理性，关键是看谁掌握规则制定权。
- **Use 土地财政 when** 一个乡镇的工资、债务、基建和接待都依赖卖地收入。
- **Use 培育地主/引进资本家 when** 地方政府把农业现代化理解为扩大经营规模和提高资本投入。

## Anti-patterns

- 以为“土地属于集体”就意味着村集体和农民拥有实际议价权。制度文本与操作现实之间存在巨大落差。
- 以为开发商愿意直接与村庄谈判。他们更愿意找能“摆平”农民、提供合法性和基础设施的政府。
- 把补偿看成技术性计价问题。补偿标准是政治决定，随项目、关系、维稳风险和上级政策变化。
- 把乡镇政府当成铁板一块。区、镇、村、组各有利益，开发收益要在层级间再分配。

## Worked Example

武镇长给作者算了一笔财政账：全镇由政府发工资的九十多人，每月工资补贴应发十三万二千元，区里下拨不到四万，缺口九万多，一年近百万；再加上基金会债务、“普九”债务两百多万，不搞开发连运转都维持不了。所以“开发就成了乡镇最大的政治”，而开发的主要途径就是卖土地。

林书记则把发展概括为“三化”：农业抓结构调整和龙头企业，工业抓盘活存量和引进民营资本，城镇抓镇区管理和规模扩张。他坦言，为了吸引客商，镇里先期投入八百万元修洲头大桥和环岛公路，“这样，就有老板来看地，每天都有两三批”。

在洲头村，省人防训练基地项目占地三百亩，涉及四组十五户承包地。政府提出每亩四千五百元、一次性了断、不丈量面积；村民则要求按实际耕种面积计算、土地占到哪里补到哪里，并担心以后地价上涨。双方的分歧不只是价格，而是**谁有权定义“面积”、谁有权决定“一次性”**。这为后续的集体抵制、分化瓦解和反复谈判埋下伏笔。

## Key Takeaways

1. 城郊乡镇的开发首先是一场财政自救，其次才是经济发展。
2. 政府在土地开发中同时扮演公共权威、土地所有者的代理人、基础设施投资者和土地商人。
3. 补偿规则的制定权比补偿数额本身更重要。
4. 村级组织在开发中被期待充当政府助手，但其“集体代表”身份又使其有空间为自己争利。
5. 农民并非被动接受者；他们会用面积、签字、阻工、上访等资源重新打开谈判。
6. “不开发，政府怎么办？”是理解乡镇行为的关键设问，不是修辞。
