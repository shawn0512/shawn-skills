# Chapter 4: 播撒希望

## Core Idea
在土地开发之外，乡镇政府还要“播撒希望”：复兴特色农产品、推动农业结构调整、引进龙头企业和资本。但这些项目往往同时是**政绩工程**：项目选择由上级决定，风险由政府承担，收益分配由政绩可见度决定。结果是“政府搞一次农调就失败一次”，而真正被寄予厚望的，仍然是土地变现。

## Frameworks Introduced

- **农业结构调整作为政绩工程** — 上级定项目、定面积、定时间，乡镇负责动员、垫资、签合同；成功是领导有方，失败是农民不配合或管理不到位。
- **诱民致富** — 政府用“三包一定”（包种子、包技术、包收购、定合同）、保底价、补贴和示范点，诱导农民改种；农民则以“等一等、看一看”回应。
- **公司 + 农户 / 订单农业** — 依托龙头企业收购，理论上锁定市场风险；实际上企业、政府、农户三方对价格、产量、质量的承诺都可能随行情变化。
- **扶强不扶弱 / 锦上添花** — 有限资金优先投向交通好、班子强、容易出成绩的村；弱村即使有正宗品牌和先发项目，也可能被替换。
- **土地变现优先于产业培育** — 农产品加工和结构调整周期长、收益薄；卖地来得快、数字大，因而更容易成为干部真正的兴奋点。

## Key Concepts

- **小镇豆** — 地方黄豆品牌，真正优质产区很小，但品牌被用于全镇产业规划。
- **范家坝 / 小岳村** — 前者偏远、穷、有正宗产地；后者靠近镇街和区治、村集体有钱，最终获得豆制品基地资金。
- **藠头** — 出口型经济作物，区里计划发展到十万亩，小镇分解到一千五百亩。
- **三包一定** — 包种子、包技术、包收购，定合同。
- **保底价** — 政府承诺的最低收购价，用于给农民“定心丸”。
- **试验点 / 基地** — 公路边、成片、靠近镇街，便于上级检查和干部督促。
- **大陈模式 vs 前王模式** — 前者政府供种肥、农民自负管理风险并分享收益；后者租地给教办、农民拿固定劳务费。
- **谢张村卖地** — 以办学名义低价出让两千亩土地，说明“产业希望”最终仍让位于土地财政。

## Mental Models

- **Use 诱民致富 when** 政府用补贴、保底价和示范点动员农民改种，但农民并不主动。
- **Use 扶强不扶弱 when** 有限资源被集中到容易出政绩的村或项目，弱村被边缘化。
- **Use 大陈/前王对比 when** 设计农业项目：有风险分担和剩余索取权，农民才有管理积极性；固定工资容易养出“铁饭碗”心态。
- **Use 土地变现优先 when** 农业项目说得热闹，但干部真正投入精力的是看地、谈价、办证。

## Anti-patterns

- 由上级拍板作物品种和面积，却要求乡镇和农民承担市场与技术风险。
- 以为签了合同、给了补贴，农民就会精耕细作。没有剩余索取权，就没有管理积极性。
- 把示范点选在公路边、靠近镇街，是为了便于检查，不一定适合作物生长。
- 以为“正宗产地”会自动带来资源。资源和资金往往跟着交通、班子实力和政绩可见度走。
- 把农业结构调整的失败简单归因于“农民不配合”，忽略种子、季节、技术、市场和政府协调的失误。

## Worked Example

前王村的藠头项目由镇政府与君山教办签租地协议，教办提供种子、化肥、农药，农户以打工形式下种、管理、收获，每亩五百元劳务费。对农民来说，这是“无风险也无大利”的安排；对政府来说，这降低了农民抵制，却也抽掉了农民精心管理的激励。

结果，前王村百余亩藠头**颗粒无收**，大陈村却长势良好、亩利可过千元。前王农民要求按一季油菜的收益每亩赔三百元；政府最后给村里五千元善后，加上先期预支的一百元，折合每亩一百五十元。镇干部认为责任在管理不到位，农民认为种子有问题、技术指导不到位；懂行的曹元新则判断，种子运回后堆在学校里捂坏了，下种又偏晚，才是主因。

这场失败没有改变区里继续扩大藠头种植的决定。政府又增加试验点，继续“播撒希望”。同一时期，谢张村则把两千亩地以每亩二点七万元低价卖给拟办大学分校的恒久公司。两相对照，农业产业化的“希望”与土地变现的“现实”高下立判。

## Key Takeaways

1. 农业结构调整在压力型体制下很容易变成面积、数字和示范点的竞赛。
2. 项目成功需要市场、技术、季节、管理和农民激励同时到位，任何一环失误都可能全盘皆输。
3. “三包一定”只能降低农民的市场风险，不能替代农民的管理激励。
4. 政府资源倾向于“扶强不扶弱”，因为政绩需要可见的回报。
5. 农业项目的失败成本最终往往由政府和村庄承担，农民则以“闹”或“不配合”转移部分损失。
6. 在城郊乡镇，土地开发始终是比农业产业化更直接、更可计算的“希望”。
