# Chapter 12: 利益交关

## Core Idea
当行政任务被“总费用承包”后，行政过程就变成了**经济过程**：镇、村、组干部都成了大大小小的“中间商”，在补偿款中杀价、留成、再分配。“花小钱办大事”表面上是节约，实际上是把公共权力商业化。与此同时，最后的征收和石场业主上京，展示了另一种利益交关：政府用“耗油”消耗对手的耐心，用拦访和接访维护稳定，而不是用法律或补偿解决问题。

## Frameworks Introduced

- **行政过程经济化** — 上级把一笔总费用包给下级，超支不补、节余自行支配；下级于是像商人一样讨价还价、控制成本、保留剩余。
- **中间商链条** — 施工方 → 镇政府 → 村委会 → 村民小组 → 农户，每一层都截留、杀价、转包；信息不对称使最底层得到最少。
- **“花小钱办大事”** — 用最少的钱摆平最多的问题；在干部那里是节约和能力，在农民那里是被压价。
- **上访博弈 / “耗油”** — 政府不正面满足诉求，而是通过拖延、冷处理、拦截和消耗时间，让对方知难而退。
- **拦访 / 接访** — 派人到上级信访地拦截、劝返、接回上访者；目标是“不出事”，不是解决问题。
- **“猴子不上树，多打几遍锣”** — 农民对“闹一次给一点”的经验总结。

## Key Concepts

- **复耕费** — 施工方按每公里九千元给政府，用于土地复耕和水系恢复。
- **总费用承包** — 政府把一笔钱包给村组，要求“摆平”所有遗留问题。
- **杀价** — 上级对下级报价大幅砍价，下级再对农民砍价。
- **留成 / 节余** — 承包者可以自行支配的剩余，用于吃饭、用车、话费、慰问等。
- **点发** — 私下给个别“刺儿头”好处，换取其不再闹。
- **耗油** — 通过拖延和冷落消耗上访者的时间、金钱和耐心。
- **硬座车票** — 政府接回上访者时买最便宜的车票，作为一种惩罚性信号。
- **“人民内部矛盾用人民币解决”** — 用钱摆平冲突的通俗说法。

## Mental Models

- **Use 行政经济化 when** 上级用“总费用承包”“超支不补、节余自留”的方式下放任务。
- **Use 中间商链条 when** 补偿款从施工方到农户层层缩水，每一层都有自己的理由。
- **Use 耗油 when** 一方时间成本低、另一方耗不起；不解决就是最有效的解决。
- **Use 拦访 when** 上访触及稳定考核，政府的第一目标是把人带回来，而不是回应诉求。

## Anti-patterns

- 以为总费用承包能提高效率。它可能提高“摆平”效率，却扭曲公共资金的用途和分配。
- 以为杀价是节约。它可能把成本转嫁给最底层的农民和村组。
- 以为上访是法律救济的替代品。它更像一种政治施压和讨价还价。
- 以为“耗油”能真正解决问题。它只是把冲突推迟或压低，积累新的不满。

## Worked Example

西气东输工程进入复耕阶段，施工方按每公里九千元把善后费用交给镇政府。宋正良副镇长对各村实行“总费用承包”：一亩给村里两百元，村里与农民交涉，一个工三十元；超支不补，节余自行支配，只要不揣进自己腰包，吃饭、用车、话费都可以报销。于是，镇干部“把公家的事当自家的事办”，尽量少花钱多办事。

在南塘湾村八组，清淤工程需要协调。村主任老万报价五千元，镇干部宋德益只给两千元；两人当着村民的面争得面红耳赤，宋德益压低嗓子提醒“小声些，莫让他们听见”。第二天，老万带组长到镇里找宋正良，宋正良绕过老万，直接给组长一千二百元，说“你请二十个工，花六百块，搞得漂漂亮亮，队里还可以挪六百块钱下来”。组长知道这是能拿到的最好价钱，但仍要叫一叫苦，最后接受。整个过程中，镇、村、组都像生意人一样讨价还价，行政空间变成了市场空间。

石场业主的上京则展示了“耗油”。第一次进京，政府派人拦截、请吃饭、买票接回，业主觉得“有面子”；第二次，二十四人直接把材料送进国家信访办，政府不再“惠顾”，而是冷处理：不主动见面、不管食宿、只买硬座票。业主在北京耗了几天，钱和时间都吃不消，内部出现分歧，最终只能回来。政府没有解决赔偿问题，却成功地把冲突从“公开上访”压回“地方谈判”。

## Key Takeaways

1. 总费用承包把行政任务变成经济交易，干部从公务人员变成“中间商”。
2. 层层杀价和留成，使最底层的农民得到最少，也让信息不对称成为治理工具。
3. “花小钱办大事”在干部那里是能力，在农民那里是被剥夺。
4. 上访是一场政治博弈，政府用“耗油”消耗对手，而不是用规则回应诉求。
5. 拦访和接访的目标是稳定，不是正义；它能降温，却不能解决根源。
6. 行政经济化会侵蚀公共权力的公共性，使治理越来越依赖私下交易。
