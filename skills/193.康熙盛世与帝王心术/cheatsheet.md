# 决策速查

## 五条核心判断规则
1. **先问合法性，再问治理**：康熙朝任何大政，先看它如何生产“得天下之正”，再看其民生/军事效果。（Ch 1）
2. **官方叙事是症状**：上谕、《实录》越强调某事，越要查它删改了什么；矛盾处即政治。（Ch 2）
3. **战争看投入，不看口号**：宣称目标与实际兵力、行动节奏不匹配时，找真正的政治 prize。（Ch 5）
4. **盛世看成本，不看蠲免**：高额赋税 + 中央集财 + 地方亏空 + 捐纳，才是“盛世”的财政结构。（Ch 6）
5. **心理看应激源，不看表演**：先定位威胁，再判断是真实情感、暂时宣泄还是政治表演。（Ch 1、Ch 3）

## 分析决策树
- **事件涉及皇帝颜面/满汉冲突/处分满洲权贵？**
  - 是 → 先做史料层累辨伪：官修 vs 私修 vs 满文档案。
  - 否 → 可直接用公开政策文本。
- **是一项“仁政/德政”？**
  - 是 → 追财政来源：高额赋税？地方存留？捐纳？蠲免是否只是逋欠转化？
  - 否 → 看其正统收益。
- **是一场战争？**
  - 是 → 比较“宣称目标/实际投入/行动节奏”，并查情报过滤链。
  - 否 → 看其对承认结构的影响。
- **是帝王异常言行？**
  - 是 → 找应激源 → 看防御机制（压抑/转移/投射/先发制人）→ 看是否遵循固定模式。
  - 否 → 按制度与利益分析。
- **是“盛世”叙事？**
  - 是 → 问“谁付钱、谁被看见、谁被排除”。
  - 否 → 看其与正统工程的连线。

## 识破信号
- **反复重述几十年前的旧罪** → 不是记忆问题，是认知图式/自我辩护。（Ch 2）
- **越强调“满汉一体”，扈从名单越单一** → 话语与制度脱节。（Ch 6）
- **蠲免越频繁，地方亏空越大** → 合法性投资与财政转移并行。（Ch 6）
- **大军压境却长期顿兵、只诱降** → 真实目标可能在别处，或准备不足、心存侥幸。（Ch 5）
- **战败后突然大谈孝道/节俭/勤政** → 从能力叙事转向道德补偿。（Ch 6）
- **下属迎合也罚、劝谏也罚** → 上级维护的不是规则，而是自我；组织已失去心理安全。（Ch 3）
- **《面谕》/遗诏前后矛盾、语义含混** → 危机文本，仓促拼合，需分层读。（Ch 3、Ch 6）

## 表里对照
| 表象 | 实质 |
|---|---|
| “得天下之正” | 对被统治民族承认的争夺 |
| 蠲免/赈济 | 高额赋税与逋欠的合法性转化 |
| “满汉一视” | 满洲特权与信息圈层 |
| 巡幸/木兰秋狝 | 满洲扈从与决策封闭 |
| 理学辩论 | 道统裁判权与政治清洗 |
| 准噶尔用兵 | 青海胡必尔汗与西藏通道 |
| 太后之丧的哀毁 | 战败后的道德权威修复 |

## 常见误判
- 把《面谕》当传位遗诏 → 它是自辩与警告。
- 把哈密事件当战争原因 → 它是口实。
- 把拉藏汗当清廷傀儡 → 双方互相利用、互不信任。
- 把玄烨晚年当单纯衰老 → 其行为仍有权威修复逻辑。
- 把盛世当全民富足 → 玄烨自己都承认另一面。
- 把心理分析当万能 → 必须先过史料考证关。
