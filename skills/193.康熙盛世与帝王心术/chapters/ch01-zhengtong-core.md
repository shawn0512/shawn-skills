# Chapter 1: 导论——争正统作为康熙朝的政治核心

## Core Idea
康熙朝的政治核心不是一般意义上的“盛世治理”，而是为大清争正统：证明“自古得天下之正莫如我朝”。三藩之乱、理学真伪、历代帝王庙、皇太子废立、准噶尔之役、蠲免与盛世宣传，都是这一命题的不同战线。作者的方法论则是：把史实考证与帝王心理分析结合，既不以官方叙事为透明事实，也不作无证据的心理悬揣。

## Frameworks Introduced
- **争正统作为历史主题**：“为大清王朝争正统，这是康熙朝的政治核心，也是清前期的历史主题。”
  - When to use: 分析康熙朝任何重大政策、人事、战争、文字狱时，先问它如何生产或捍卫统治合法性。
  - How: 追三项——谁来承认（汉人士大夫/蒙古/西藏）、凭什么承认（得国之正/盛世/道统）、不承认会怎样（文字狱、军事征伐、财政动员）。
- **心理史学双重证据法（“口诉与化验”）**：君主的自述只是“症状”，不是“诊断”；必须与过硬史料互证，再判断其情感是真实思想、暂时宣泄，还是假相。
  - When to use: 解读《面谕》、上谕、朱批、起居注中的帝王自辩时。
  - How: 先做史料层累辨伪（官修/私修/满文档案对勘），再定位应激源，最后看言行是否遵循固定心理模式。
- **表里结构**：思想意识大体由社会存在决定；但它转化为行为的时机、场合与形式，很大程度取决于心理人格。
  - When to use: 解释同一利益结构下，为何出现特定风格的政治行为（夸诞、拖延、突然爆发）。
  - How: 把“客观利益”与“主观形式”分开写，避免用阶级或民族本质直接推出个人行为。
- **“一切服从于政治”**：玄烨所有重大举措，其目的皆在证明清廷得天下最正；用今天的话说，即一切服从于政治。
  - When to use: 评估某项“德政”或“武功”的真实优先级。
  - How: 比较其宣传收益、财政成本与对汉人承认的边际效果。

## Key Concepts
- **正统**：政权的合法性，属于政治道德与主观承认范畴，不等同于单纯武力占有。
- **治统 / 道统**：治统是君主统治权，道统是儒家道义与学术正统；玄烨晚年要兼而有之。
- **满汉对立**：清初民族征服与歧视造成的结构性敌意，作者反对用“阶级矛盾已转化”一笔抹去。
- **康熙盛世**：被后世高度推崇的治世叙事；作者将其视为需要追问代价与财政机制的“说法”。
- **汉地中国**：清朝统治的财政与政治基本盘；与“内亚背景”相对，作者强调二者并存而后者不能否定前者。
- **伪理学**：玄烨用以打击汉人理学名臣的话语武器，以“公私”与“行事”判定学术真伪。
- **合法性投资**：为获得被统治民族承认而付出的宣传、蠲免、战争与制度成本。

## Mental Models
- **Use “这项政策在生产哪种正统？” when** 面对康熙朝任何“仁政”或“武功”——先找它与“得天下之正”的连线。
- **Think of 上谕 as 症状，not 判决书**：它透露焦虑与意图，但不能直接当事实；必须与档案、私修史、满文奏折对勘。
- **Use “承认的边际收益” when** 评估蠲免、赈济、文字狱：它们常是向汉人购买承认，而非单纯民生措施。
- **Use “客观利益 / 主观形式” when** 解释帝王为何在同类问题上时而宽仁、时而暴烈：利益解释方向，心理人格解释形式。

## Anti-patterns
- **盛世模式**：改头换面重复清代官修史书，把“盛世”当既定事实而非待解释的建构。
- **公式化矛盾论**：以“民族矛盾已转化为阶级矛盾”抹去满汉对立，导致读不懂玄烨的猜疑与报复。
- **现代观念强加**：用当代民族国家或“新清史”单一定性直接套古人，忽略当时人的天下观与承认结构。
- **只考证不解释**：堆积史实而不追问政治核心，结论无法逐层提升。
- **无证据心理分析**：把任何异常言行都归为“心理”，却不先做史料辨伪与应激源定位。

## Worked Example
戴名世《南山集》案是“正统命题制度化”的缩影。康熙五十年（1711）案发，九卿议罪已称“我朝定鼎燕京，剿除流寇，顺天应人，得天下之正，千古之所未有”。五十一年玄烨批旨只说“朕本凉德，惟赖祖考得国之正，积福之深”。到五十六年《面谕》，才升级为“自古得天下之正，莫如我朝”。作者把这条时间线放在四十七年初废太子之后：储位危机动摇国祚信心，于是文字狱、礼部议礼、帝王庙重排与《面谕》接连出场，把一句司法判词逐步抬升为帝国最高纲领。分析时要问：每一步升级，回应的是哪一次承认危机？

## Key Takeaways
1. 读康熙朝，先抓“争正统”这一政治核心，再看具体政策如何服务它。
2. 官方上谕是症状，不是事实；先辨史料层累，再谈心理。
3. 满汉对立是理解玄烨行为的主轴之一，不能用“盛世”叙事抹平。
4. 盛世不是免费的好运，而是一套财政、宣传与承认的政治工程。
5. 心理分析必须受史料约束：先定位应激源，再判断防御机制。
