# Chapter 5: 准噶尔之役与玄烨的兴兵之由——意在青海

## Core Idea
康熙五十四年清廷因哈密事件大举兴兵，表面目标是准噶尔，实际重心却在青海：控制里塘胡必尔汗、压服青海台吉，并为日后经青海入藏预留筹码。玄烨对准噶尔与西藏的情报长期误判，导致两路大军耀兵数年、西藏失守、入藏清军覆没；这场战争因此不是“势所必然”，而是虚矫心态与侥幸心理的产物。

## Frameworks Introduced
- **天下观 / 边界限制双轨模型**：观念上，玄烨自居“天下主”“万国元后”，凡信仰所至即天下所至；实践上，清廷与厄鲁特、西藏之间有明确疆界（打箭炉、西宁、哈密一线），并一再声明“原非为得藏里土地人民”。
  - When to use: 分析帝国扩张话语：不要把宇宙论宣称直接当成实际领土政策。
  - How: 分别列出“宣称的天下”“实际驻防与册封关系”“越界时的反应”，看三者落差。
- **战略重心错位识别法**：当战争宣称的目标与兵力部署、行动节奏不匹配时，寻找真正的政治 prize。
  - When to use: 分析“声东击西”或“一箭双雕”的军事决策。
  - How: 比较各方投入——哪里迅速果决、哪里顿兵不前；哪里用兵威、哪里用谈判。
- **信息误判链**：风闻与误导 → 玄烨偏信 → 错误判断准军入藏路线 → 救援迟缓 → 西藏失守。
  - When to use: 分析高压体制下的情报失败。
  - How: 标出信息源、过滤者、君主既有成见，以及“与成见相符的信息如何被优先采纳”。
- **多角宗教—政治博弈**：清廷、准噶尔、和硕特拉藏汗、第巴、青海台吉、达赖喇嘛互相利用；达赖喇嘛的封号与转世认定，是动员蒙古各部的核心资源。
  - When to use: 分析西藏、蒙古与中原王朝的关系。
  - How: 把“宗教合法性”“汗位封号”“地盘与兵源”分开，再看各方如何交换。

## Key Concepts
- **准噶尔**：卫拉特蒙古强部，策妄阿喇布坦时期与清廷争夺西藏、青海与蒙古霸权。
- **策妄阿喇布坦**：准噶尔部首领，五十六年派策零敦多布偷袭西藏。
- **策零敦多布**：准军入藏统帅，率约五千五百至六千人，绕戈壁、越大雪山，五十六年十月攻占拉萨。
- **拉藏汗**：和硕特部汗王，控制西藏；清廷册封“翊法恭顺汗”，但双方互不信任。
- **第巴桑结嘉错**：西藏摄政，五世达赖圆寂后匿丧，扶植六世达赖仓央嘉错，后被拉藏汗所杀。
- **六世达赖**：仓央嘉错；其废立与真假之争是清廷、拉藏、青海台吉博弈的焦点。
- **里塘胡必尔汗**：里塘出现的达赖转世灵童（噶桑嘉措），青海右翼台吉要求册封，拉藏汗指其为假。
- **青海台吉**：固始汗后裔，分左右翼；察罕丹津、罗卜藏丹津是关键人物。
- **哈密事件**：五十四年准噶尔扰哈密，成为清廷大举兴兵的口实。
- **噶斯口**：青海西北要隘，准噶尔经青海入藏的通道；清廷初期疏于驻防。
- **图理琛使俄**：康熙五十一年至五十四年出使土尔扈特阿玉奇汗，实为稳住侧翼、试探对准噶尔的支持。
- **天下观**：以“天下主”自居的普遍主义话语；与“边界限制”构成表里。

## Mental Models
- **Use “宣称目标 / 实际投入” when** 判断一场战争的真实目的：口号指向准噶尔，最快最硬的行动却落在青海。
- **Use “天下观是话术，边界是事实” when** 读清朝扩张叙事：两者同时存在，不能互相取消。
- **Use “情报过滤链” when** 解释为何君主总在关键时刻误判：不是没信息，而是信息被成见筛选。
- **Think of 达赖转世 as 合法性货币**：谁掌握认定权，谁就能动员蒙古；军事行动常是争夺这张货币的延伸。

## Anti-patterns
- **把哈密事件当战争原因**：它只是口实；玄烨的关注重心在里塘胡必尔汗。
- **把清准矛盾当“必然一战”**：作者认为五十四年前矛盾未激化到非战不可。
- **把拉藏汗当清廷傀儡**：玄烨一直怀疑拉藏勾结准噶尔图谋青海，双方是互相利用。
- **照抄玄烨上谕里的准军路线**：其中夹杂误判与事后掩饰，需用满文奏折、拉藏使者供词校正。
- **忽视青海台吉的独立利益**：他们既怕准噶尔，也怕清军借机进驻，故在交人、借道、出兵上反复摇摆。

## Worked Example
康熙五十四年四月初六，出使西藏调查里塘胡必尔汗真伪的众佛保回京，奏报班禅认定该灵童为假，而青海右翼台吉察罕丹津等坚持其为真，双方争执不下。八天之后，玄烨得知准噶尔兵侵扰哈密。清廷随即以两路大军出巴里坤、科布多，摆出合击准噶尔之势；但此后两三年，清军只是耀兵边境、不断诱降，甚至乞援于俄罗斯，迟迟不肯深入。

与此同时，清廷在青海的动作却迅速果决：遣阿齐图召集青海台吉会盟，以西安满兵、西宁标兵、四川兵马相威胁，迫使察罕丹津、罗卜藏丹津于五十五年三月将胡必尔汗送至塔尔寺；随后立即撤回四川兵，并改组青海左右翼。作者据此判断：五十四年玄烨之忧不在准噶尔，而在青海胡必尔汗。所谓“两路大军”，很大程度上是为一箭双雕——既威胁准噶尔，又逼青海就范。

这一判断在五十六年被反证：策零敦多布率准军绕道入藏，攻占拉萨，杀拉藏汗；玄烨此前对准军路线的判断（经噶斯口/青海）落空，救援迟缓。五十七年色楞、额伦特率数千清军仓猝入藏，全军覆没。战争的真实重心与公开目标之间的错位，最终由西藏的失守买单。

## Key Takeaways
1. 读战争，先比较“宣称目标”与“实际投入”，真实意图常藏在行动节奏里。
2. 玄烨的天下观是普遍主义的，但实际政策受明确边界与力量对比约束。
3. 准噶尔之役的重心是青海与达赖转世，不是哈密，也不是单纯的准噶尔本部。
4. 情报失败往往不是信息不足，而是君主成见过滤了不利信息。
5. 西藏、蒙古的宗教合法性，是清朝扩张无法回避的战场。
