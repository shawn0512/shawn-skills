# 决策速查（Cheatsheet）

## 一、经济形势判断

| 症状 | 先做什么 | 政策组合 | 避免 |
|------|----------|----------|------|
| 房地产/开发区/股市过热，货币投放异常 | 管住货币信贷总闸门 | 适度从紧 + 16条式金融措施 + 投资清理 | 一刀切全面紧缩 |
| 外需断崖、出口负增长、内需不足 | 扩大内需 | 积极财政 + 稳健货币 + 基础设施 | 人民币竞争性贬值 |
| 居民储蓄高、产能过剩、项目少 | 财政向银行发债 | 国债→基础设施→消化产能→扩税基 | 把赤字用于"吃饭财政" |
| 区域差距扩大、东部产业饱和 | 西部投资 | 基础设施 + 生态 + 科技教育 | 只上项目不改善生态/人才 |

## 二、财政风险四问

1. **流量**：赤字/GDP多少？（书中2002年约3%）
2. **存量**：国债余额/GDP多少？（2001年约14%，2002年约16%；书中参照警戒线20%）
3. **用途**：建设性支出还是经常性"吃饭"？
4. **资产**：形成什么资产、能否产生回报？（5100亿元国债带动2.5万亿元工程）

> 判断规则：**当**赤字用于建设、债务在警戒线内、资产可回报时，**不**因"有赤字"而否定政策；**当**赤字用于养人、项目无市场时，**立即**收紧。

## 三、国企改革决策树

- 亏损面被引用 → 先问口径：按企业数还是按税利？
  - 按个数：7.9万家工业企业、49%亏损面（小企业多，易夸大）
  - 按税利：500家特大企业占85%税利、亏损面10%
- 企业困难 → 分因：产能过剩→兼并压产；债务重→债转股/资产管理公司；冗员→再就业中心+三条保障线；机制僵化→股份制、政企分开。
- 是否私有化？→ **否**。股份制是公有制实现形式；国家只对极少数关键企业控股。

## 四、金融风险处置

- 个别机构资不抵债 → 不兜底非政府担保债务；用重组、注资、债转股；强调"不要破出甜头"。
- 银行不良高 → 剥离存量给资产管理公司；同步改革治理，防新增。
- 资本项目开放 → **只有**监管能力到位才开放；先经常项目。

## 五、开放谈判规则

- 先定性质：相互需要，不是单方乞求（"13年不加入也活得很好"）。
- 让步换什么：规则准入、改革动力、市场互惠。
- 底线：关键领域控股、发展中国家地位、过渡期。
- 对方超底线 → 对等反问（"你们的民航也只允许外资25%"）。
- 对方要得太多太快 → "最后可能什么也得不到"。

## 六、农业与社保

- 粮食丰收、库存高 → 退耕还林/还草/还湖 + 结构调整 + 农民培训。
- 农民负担重 → 费改税：取消乡统筹村提留和乱收费，提高正税，中央转移支付补缺口；先试点后推广。
- 国企下岗 → 再就业服务中心（过渡）→ 三条保障线 → 并轨失业保险。

## 七、反腐与政府管理

- 管理松弛 → "严"字 + 法制闭环：立法、执法、公开、监督；避免运动式。
- 腐败被归因政体 → 回到"法制是否健全、执法是否坚决"。
- 选突破口 → 走私、金融等链条长、可追赃领域；追缴收入用于民生。
- 机构改革 → 三定（职能、机构、编制）；核心是职能转变，不是简单减人。

## 八、港澳与外交

- 香港求助 → 特区政府提出请求，中央才"不惜一切代价"；不主动接管。
- 香港内部争议 → 权限分层：特首 → 特区政府 → 中央发言人；不属于职权不表态。
- 中美 → 说明真相、增信释疑；竞争不等于敌人；不把台湾与WTO/人权挂钩。
- 无证据指控 → 两个"过低估计" + 动机反证。
- 贸易逆差 → 先拆口径（运费保险、香港转口、走私、服务贸易），再谈开放。
- 台湾 → 一个中国底线；武力针对"台独"和外国干涉；承认原则什么都可以谈。

## 九、答问快速规则

| 情形 | 动作 |
|------|------|
| 问题复杂/带敌意 | 定调 → 事实 → 边界 |
| 前提错误 | 先纠正前提，再回答 |
| 对方用类比设陷阱 | 承认有趣 → 指出类别不同 → 回到原命题 |
| 对方用单一数字 | 问口径 → 多口径对比 |
| 被要求预测 | 条件句："如果……那么……"；不知道就说不知道 |
| 超出职权 | "这应由谁回答"；给转交路径 |
| 事实不利 | 承认 → 给进展 → 给时间表 |
| 人身攻击/标签 | 幽默自嘲 → 回到实质 |
| 气氛紧张 | 共情（"既然你们有气……"）→ 说明真相 |
