# Chapter 4: 加入WTO与对外开放

## Core Idea
加入WTO不是单方面"送礼"，而是以开放促改革、以规则换市场的战略交易；让步有底线、开放有顺序、过渡期有必要，最终要利大于弊。

## Frameworks Introduced
- **"复关/入世"的长期谈判框架**
  - 中国1986年申请复关，谈判13年；"黑头发都谈成白头发了，该结束这个谈判了"。
  - 三条判断：WTO没有中国就缺乏代表性；中国改革开放积累了监管能力和承受能力；中国准备作最大让步，但必须权利义务平衡。
  - 当谈判久拖不决时，用"相互需要"而非"单方乞求"定位：不是非加入不可，而是加入对双方都有利。
- **发展中国家地位 + 过渡期**
  - 中国以发展中国家身份加入，市场开放要有时间表、有过渡期。
  - 当对方要求"完全达到WTO标准"时，回答：可以朝标准走，但必须给过渡期，不能要求一步到位。
- **权利与义务平衡**
  - 享受最惠国待遇、国民待遇、争端解决机制；履行关税减让、市场准入、透明度、知识产权保护。
  - 当对方只谈中国义务、不谈中国权利时，明确"协议必须是平衡的"。
- **渐进开放顺序**
  - 制造业先开放，服务业（金融、保险、电信）有步骤开放；外资可参股，但关键领域保留控股底线。
  - 当对方要求提高持股比例时，用"对等原则"反问：你们的民航、金融也对外资设限。
- **"利大于弊"的条件论**
  - 入世本身有利有弊，能否利大于弊取决于：企业竞争力、法制与监管、政府职能转变、人才准备。
  - 当被问"会不会导致大量下岗"时，先承认结构性失业压力，再讲积极就业政策、社保和培训。

## Key Concepts
- **复关**：恢复中国在关税及贸易总协定（GATT）中的缔约国地位。
- **WTO**：世界贸易组织，1995年成立，管理世界经济和贸易秩序。
- **最惠国待遇**：一方给予另一方的贸易优惠，应立即无条件给予所有成员。
- **PNTR**：永久性正常贸易关系，美国国会给予中国的重要立法安排。
- **国民待遇**：外国产品、企业在本国市场享受与本国同类同等待遇。
- **市场准入**：允许外国商品、服务、资本进入本国市场的条件。
- **过渡期**：发展中国家履行开放义务的缓冲时间。
- **反倾销**：进口国对低价倾销产品征收附加税；入世后可用WTO机制应对。
- **知识产权保护**：专利、商标、版权等保护；是入世承诺和吸引外资的基础。

## Mental Models
- 当对方要求超出底线的让步时，用"要得太多、太快，最后可能什么也要不到"提醒机会成本。
- 当国内担心开放冲击时，用"竞争提高质量"而非"保护落后"来定调，同时配套过渡期和社保。
- 当谈判陷入僵局时，区分"面子"与"里子"：联合声明、原则承诺可以拿，核心利益不能让。
- 当被指"中国需要WTO"时，用"13年不加入也活得很好"校正议价地位，避免被当成求和方。
- 当评估开放收益时，把"规则锁定改革"算进来：入世是外部锚，能推动国内法制和政府职能转变。

## Anti-patterns
- **为入世而无限制让步**：短期换到门票，长期丧失产业政策和调控空间。
- **只开放、不监管**：金融、电信等领域若监管能力不足，开放会放大风险。
- **保护落后企业**：用行政壁垒维持低效产能，最终拖累整体竞争力。
- **把入世当成万能药**：不配套国内改革，开放红利会被内部扭曲吞噬。
- **情绪化对待摩擦**：动辄喊制裁，不如用WTO争端解决机制和谈判处理。

## Worked Example
1999年4月《华尔街日报》采访，记者追问：中国是否已作最大让步、是否到此为止？
回答结构：
1. 校正定位：中国绝不是乞求加入WTO，不参加也活得很好；让步是顾全中美友好合作大局。
2. 讲清让步内容：电信过去完全不开放，现在允许外资参股25%—30%，过渡期后还可放宽，但中国必须控股。
3. 用对等原则反驳：美国民航也只允许外国投资25%，韩国、中国台湾地区也有外资比例限制，"并不只是中国才有"。
4. 给谈判边界：不是不能再让，而是美国现在要求再让的"没有道理"；要得太多太快，可能什么也得不到。
5. 保留替代选项：世界上不只有一个美国，还有欧洲和其他国家。
同一时期在纽约还讲：如果协议此时达成，回国可能被指责"送大礼、出卖国家利益"；因此宁可晚签，也不签一个国内无法接受的协议。

## Key Takeaways
1. 入世是战略交易，不是单方恩赐；谈判要同时管理对外议价和对内说服。
2. 开放顺序：先制造业、后服务业；先经常项目、后资本项目。
3. 过渡期不是拖延，而是给产业调整和监管能力建设留时间。
4. 关键领域保留控股底线，用对等原则回应不合理要求。
5. 入世红利取决于国内改革配套：法制、监管、竞争政策、社保。
6. 贸易摩擦要用规则和机制处理，同时保留反制手段。
