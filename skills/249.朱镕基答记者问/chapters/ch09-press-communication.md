# Chapter 9: 记者应对与政策沟通

## Core Idea
高质量答问不是背"标准答案"，而是先给框架、再用事实、最后划边界；面对敌意问题，先拆前提、再重设议程，既不回避，也不越权。

## Frameworks Introduced
- **"定调—事实—边界"三段式**
  - 定调：先给原则、框架或结论，让听众知道你的立场。
  - 事实：用数字、案例、时间表支撑，而不是形容词。
  - 边界：说明能做什么、不能做什么、谁来做、什么时候做。
  - 当问题复杂或带敌意时，用三段式防止被对方的问题牵着走。
- **前提澄清（先拆问题，再回答）**
  - 例：西方质疑白皮书引发紧张，回答"先有'两国论'，后有白皮书"——把因果顺序纠正过来。
  - 例：记者说"中国盗窃美国军事机密"，回答先指出这是"天方夜谭"，再给两个"过低估计"。
  - 当问题内含错误假设时，不要顺着答，先纠正假设。
- **类比拆解**
  - 例：CNN记者用"妻子要离婚就威胁杀掉她"类比台湾问题，回答"这个例子很风趣，但是跟我的讲话风马牛不相及"，再重申武力针对"台独"和外国干涉，不针对台湾人民。
  - 当对方用类比设陷阱时，先承认类比有趣，再指出类别不同，最后回到原命题。
- **责任分层与权限纪律**
  - 例：香港基本法第23条争议，"这些话不要由我来讲，首先由董建华特首来讲，其次是中央政府还有发言人"。
  - 例：辜振甫访问细节，"我请钱其琛副总理介绍一些情况"。
  - 当问题超出职权或应由他人发布时，明确转交，不抢话、不越权。
- **不确定性管理**
  - 例：人民币何时成为世界货币，"不应该由我来回答，而且现在还言之过早"。
  - 例：美国经济何时复苏，"他们自己都说不清，我能说得清吗？"
  - 例：继任者是谁，"答案连我都不知道，所以我就没办法告诉你"。
  - 当被要求预测或假设时，承认信息边界，不编造确定性。
- **承认不足 + 给进展**
  - 例：反腐"我们对这个工作并不十分满意"，但接着讲查办走私、海关税收翻倍、8400万低收入者受益。
  - 例：人权"并不是没有缺点"，但讲宗教自由、圣经印刷、教徒增长。
  - 当事实不利时，先承认，再给可核查的改进，避免全程防御。
- **幽默与自嘲化解敌意**
  - 例：被称"赤字总理"，回答"我从来不接受荣誉称号或者荣誉学位"，查了20几个国家都有赤字，最后"这个'荣誉'称号，奉送回去"。
  - 当气氛紧张时，幽默能降低对抗，但不能替代实质回答。
- **数字锚定**
  - 例：国企亏损面49% vs 500家特大企业占85%税利、亏损面10%。
  - 例：赤字3098亿元、占GDP 3%，国债余额2.56万亿元、占16%。
  - 当对方用笼统指控时，用可核查数字把争论变成可讨论的问题。
- **"即席回答"优于"标准答案"**
  - 例：接受《华尔街日报》采访前，秘书班子起草了"标准答案"，他认为没有新闻价值，决定即席回答。
  - 即席回答显得真诚、有信息量，也更容易被对方引用。
  - 当准备时间充足时，准备的是事实和框架，不是逐字稿。

## Key Concepts
- **定调**：先给问题的解释框架，决定后续讨论方向。
- **前提**：问题中隐含的假设；错误前提会导致错误答案。
- **责任分层**：不同层级、不同部门按权限发言。
- **信息边界**：不知道自己不知道的事，不假装知道。
- **可核查事实**：能被对方查证的数字、案例、时间表。
- **共情式反驳**：先承认对方情绪合理，再纠正事实或逻辑。
- **自嘲**：用幽默消解人身攻击，保持主动。

## Mental Models
- 当问题带敌意时，先用一句话定调，再用事实回答；不要从防御姿态开始。
- 当对方用数字攻击时，先问"这个数字怎么算的"，再给多口径对比。
- 当被要求预测时，用"条件"代替"日期"：如果……那么……；否则不承诺。
- 当问题超出职权时，明确"这应由谁回答"，比勉强作答更专业。
- 当事实不利时，承认 + 进展 + 时间表，比否认更可信。
- 当对方用类比设陷阱时，先拆类比，再回到原则。

## Anti-patterns
- **背标准答案**：听起来空洞，缺乏新闻价值，容易被追问击穿。
- **回避所有敏感问题**：失去可信度，等于把议题让给对方。
- **与记者争吵**：赢了辩论，输了传播。
- **过度承诺或预测**：兑现不了会反噬；不确定性要用条件句管理。
- **越权表态**：替其他部门或特区政府发言，制造新的矛盾。
- **用形容词代替数据**："很大""很好""很快"无法说服专业听众。
- **否认一切**：连明显的问题都不承认，会削弱所有正面信息。

## Worked Example
场景一：1999年访美前，《时代》周刊问：华盛顿反华情绪严重，你的访问像进入"雷区"，中国还值得把美国当朋友吗？
应对拆解：
1. 定调：不认为访问是"地雷阵"，无非气氛不太好；访问目的是说明真相、恢复建设性战略伙伴关系。
2. 共情：承认美国出现反华潮流，理解对方国内政治，甚至自嘲"我也成了一个受害者"。
3. 事实：两个"过低估计"拆解间谍指控；用中国不首先使用核武器、停止核试验、导弹互不瞄准协议反证动机。
4. 边界：访问不签城下之盟；中国不是非要加入WTO。
5. 收束："既然你们有气，我就要去给你们消消气。"
场景二：2002年人大记者会，香港报纸称他为"赤字总理"。
应对拆解：
1. 定调：不接受这个"荣誉称号"。
2. 事实：查了20几个国家，2000年19个国家都有赤字；中国赤字3098亿元、占GDP 3%，国债余额2.56万亿元、占16%，都在警戒线内。
3. 用途：赤字用于基础设施，不是"吃"掉；5100亿元国债带动2.5万亿元工程，留下优质资产。
4. 反讽收束："对不起，我不能接受'赤字总理'这个'荣誉'称号，奉送回去。"
两例共同点：不被对方的标签定义，用事实重设评价标准，最后用一句有力的话收束。

## Key Takeaways
1. 先定调，再给事实，最后划边界；不要从防御开始。
2. 遇到错误前提，先拆前提，再回答问题。
3. 数字要可核查、有口径、能对比；形容词说服不了专业听众。
4. 不知道就说不知道；预测用条件句，承诺留余地。
5. 超出职权的问题，明确转交，不越权。
6. 承认不足反而增加可信度，但要紧跟改进和进展。
