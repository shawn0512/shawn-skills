# Chapter 8: 中美关系与国际战略

## Core Idea
中美关系的处理原则是"说明真相、增信释疑、守住底线"：以建设性战略伙伴关系为框架，竞争不等于敌人；台湾是底线但不与其他议题挂钩；国际经济秩序要循序渐进，不能把一种模式强加给所有国家。

## Frameworks Introduced
- **建设性战略伙伴关系**
  - 对"战略"的界定：长期稳定，不是军事同盟；中国外交不结盟、不针对第三者。
  - 伙伴关系与竞争并不矛盾：经济全球化下，国与国既有竞争也有合作。
  - 当美方称中国为"竞争对手"时，回应"竞争对手不一定是敌人"，并引用对方"贸易上是伙伴"的表态，缩小分歧。
- **公共外交"消气"框架**
  - 面对美国国内反华情绪，不回避、不对骂，而是"既然你们有气，我就要去给你们消消气"。
  - 访问目的：说明真相、恢复关系势头，而不是签城下之盟。
  - 当对方国内政治气氛恶化时，用"去沟通"而非"去对抗"定位，降低访问预期、争取中间派。
- **"两个过低估计"**
  - 回应"中国盗窃美国军事机密"：第一，过低估计了美国的保密能力；第二，过低估计了中国自主开发军事技术的能力。
  - 用逻辑反证：中国已声明不首先使用核武器、停止核试验、签订导弹互不瞄准协议，没有动机冒政治和道德风险去窃密。
  - 当面对无证据指控时，用"对方能力 + 我方能力 + 动机"三问拆解。
- **贸易逆差的多因素核算**
  - 美方数字569亿美元、中方211亿美元，差异来自：进口计价含运费保险、出口计价不含；经香港转口的增值；走私；服务贸易。
  - 经学者修正后约365亿美元（货物约350亿美元）。
  - 当对方用单一逆差数字施压时，先拆解统计口径，再谈市场开放和产业分工。
- **台湾问题的"底线 + 留门"**
  - 底线：一个中国原则；任何形式的"台独"都不能允许；不承诺放弃使用武力，针对"台独"势力和外国干涉，不针对台湾人民。
  - 留门：承认一个中国，什么问题都可以谈；"和平统一、一国两制"；统一后不干涉台湾政治经济制度，不派军队，台湾领导人可到中央政府任副职。
  - 三通原则：一国两制、直接三通、双向交流、互惠互利。
  - 当对方把台湾与其他议题挂钩时，明确"不把台湾问题跟中美关系的其他问题联系起来"。
- **周边与多边布局**
  - 10+3、10+1：支持东盟在2002年实现地区自由贸易化，中国入世降税时间表与东盟自贸区接轨。
  - 上海合作组织：边界信任、裁军、多边经贸合作。
  - 中日："以史为鉴、面向未来"；历史教科书问题不容歪曲，但不影响高层往来。
  - 中俄：战略协作伙伴关系，《中俄睦邻友好合作条约》。
  - 当"中国威胁论"出现时，用"竞争不等于威胁"和实际让利（援助、降税、开放）回应。

## Key Concepts
- **建设性战略伙伴关系**：长期稳定、不结盟、不针对第三方的合作关系。
- **最惠国待遇/PNTR**：美国对华正常贸易关系安排，是中美经贸的基石。
- **中美三个联合公报**：中美关系的政治基础，包括一个中国承诺。
- **NMD/TMD**：美国国家导弹防御系统/战区导弹防御系统；中国反对，认为违反《反导条约》、引发军备竞赛。
- **一个中国原则**：台湾是中国一部分；是两岸对话的前提。
- **八项主张**：江泽民关于台湾问题的八点政策主张。
- **"听其言、观其行"**：对台湾当局领导人不轻信表态，看实际行动。
- **10+3/10+1**：东盟与中日韩/东盟与中国的合作机制。
- **上海合作组织**：中国、俄罗斯及中亚国家的区域合作组织。
- **"中国威胁论"**：周边国家对中国崛起可能带来竞争或威胁的担忧。

## Mental Models
- 当对方国内政治气氛恶化时，用"说明真相、增信释疑"而不是"对等报复"；访问本身是沟通机会。
- 当对方用单一数字（逆差、军费）施压时，先拆统计口径和多因素，再谈政策。
- 当面对无证据指控时，用"能力—动机—反证"三问，而不是简单否认。
- 当主权底线被触碰时，明确底线，同时给对话留门：承认原则，什么都可以谈。
- 当周边出现"威胁论"时，用实际让利和机制化合作（自贸区、10+3）降低恐惧。
- 当历史问题出现时，区分"原则"与"关系"：历史不能歪曲，但不轻易中断高层往来。

## Anti-patterns
- **情绪化对抗**：对骂会强化对方国内反华共识，失去中间派。
- **把台湾问题与WTO、人权等议题挂钩**：等于接受对方把核心利益当筹码。
- **接受对方议程设定**：只回答对方关心的问题，不主动设置议题。
- **只讲原则、不给数据**：难以说服对方公众和工商界。
- **对周边只谈善意、不给实惠**： "中国威胁论"不会自动消失。
- **在历史问题上以经济关系为由沉默**：会失去道义高度和国内支持。

## Worked Example
1999年访美前后，美国《时代》周刊问：华盛顿反华情绪严重，你的访问像进入"雷区"，中国还值得把美国当朋友吗？
回答结构：
1. 承认气氛：中美元首互访后势头本来很好，但美国出现反华潮流，访问会遇到敌意和不友好气氛。
2. 拒绝"雷区"比喻："这不是个'地雷阵'，无非是气氛不太好"；访问目的是说明真相、恢复建设性战略伙伴关系的好势头。
3. 解释对方动机：美国内部斗争把中美关系当牺牲品；《商业周刊》封面把他照片弄得"像个死人"，他也是受害者。
4. 回应间谍指控：两个"过低估计"——美国保密能力、中国自主开发能力；中国没有动机窃密。
5. 给访问定位："既然你们有气，我就要去给你们消消气"。
在纽约经济俱乐部，他进一步说：此时若签WTO协议，回国可能被指"送大礼"；中国不是非要加入WTO，让步是为顾全中美关系大局。这种"放低预期、抬高原则"的组合，避免了被国内视为软弱。

## Key Takeaways
1. 中美关系要管理预期：既讲原则，也讲对方国内政治约束。
2. "战略伙伴"指长期稳定，不结盟、不针对第三方；竞争与伙伴可以并存。
3. 面对无证据指控，用能力、动机、反证三段拆解。
4. 贸易逆差先拆统计口径，再谈市场开放和产业分工。
5. 台湾问题是底线，但不接受与其他议题捆绑；底线之外留足对话空间。
6. 周边战略要用机制和实惠降低"中国威胁论"，历史问题坚持原则但不轻易断联。
