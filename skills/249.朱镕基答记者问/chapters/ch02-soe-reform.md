# Chapter 2: 国有企业改革与职工安置

## Core Idea
国企改革的目标不是私有化，而是用"三年两目标"把亏损企业拖出困境、把骨干企业推向现代企业制度；核心手段是政企分开、所有权与经营权分开、股份制改造，并用再就业服务中心和社保体系承接转型代价。

## Frameworks Introduced
- **"三年两目标"（1998—2000）**
  - 目标一：大多数国有大中型亏损企业摆脱困境。
  - 目标二：大多数国有大中型骨干企业初步建立现代企业制度。
  - 当改革需要稳定预期时，用"阶段性目标"而非"彻底解决"来承诺，避免把长期机制问题压缩进短期政治周期。
- **现代企业制度"十六字"**
  - 产权清晰、权责明确、政企分开、管理科学。
  - 当国有企业效率低、约束软时，先查四件事：产权是否清晰、责任是否到人、政府是否越位、管理是否专业。
- **"抓大放小"**
  - 抓大：500家特大型企业贡献全国税收和利润的85%，其中亏损面仅10%；用大企业集团、股份制、上市做强。
  - 放小：中小型企业采取多种形式放活，包括股份合作、出售、租赁、兼并。
  - 当"亏损面49%"被用来证明国企整体失败时，先问统计口径：7.9万个工业企业中大量是几十人的小企业，按个数统计会夸大问题。
- **股份制作为公有制的实现形式**
  - 国家只对极少数企业控股；多数企业面向公众发行股票，提高公开性、透明度，接受群众监督。
  - 当被问"是不是私有化"时，用"所有制性质"与"经营形式"分开回答：股份制不等于私有化。
- **再就业服务中心 + "三条保障线"**
  - 中心负责发基本生活费、代缴社保、提供再就业服务，是社保不完善时期的过渡安排。
  - 三条保障线：下岗职工基本生活保障、失业保险、城市居民最低生活保障。
  - 当大规模下岗不可避免时，先用过渡性机构承接，再并轨到失业保险。

## Key Concepts
- **政企分开**：政府不直接经营企业，企业面向市场自主经营。
- **所有权与经营权分开**：国家保留所有权，企业按市场规则运营。
- **债转股**：把银行对企业的债权转为股权，降低企业负债、化解银行不良。
- **兼并重组**：通过优势企业整合困难企业，避免一律破产。
- **"铁饭碗"**：终身就业、不能辞退的旧体制；打破它才有竞争。
- **减员增效**：通过人员分流降低冗员成本，但必须与再就业配套。
- **重复建设**：行政干预造成的同质产能，是国企亏损的重要历史原因。
- **"一个人的饭三个人来吃"**：过度就业导致效率低下，是旧体制的典型病症。

## Mental Models
- 当有人用"亏损企业占比"唱衰国企时，用"数量占比 vs 税利占比"双口径校正：500家特大企业占85%税利，亏损面仅10%。
- 当改革触及人员问题时，先建承接机制（再就业中心、三条保障线），再推进减员，否则社会成本会反噬改革。
- 当讨论所有制时，把"所有权归谁"与"以什么形式经营"分开；股份制、上市、混合所有制都可以是公有制的实现形式。
- 当企业困难时，先分因：重复建设、盲目贪大、过度就业、机制僵化；不同病因用不同药，不能一律私有化或一律关停。

## Anti-patterns
- **私有化**：书中明确拒绝，认为不符合中国国情，会导致国民经济崩溃。
- **快速关停、把职工直接推向社会**：没有社保承接，会引发不稳定并逆转改革共识。
- **行政干预、重复建设**：项目投产即无市场，挤垮原有企业。
- **盲目贪大求全**：资金不足仍上大项目，迫使银行超发贷款，形成债务包袱。
- **只改产权、不改治理**：换了牌子但政企不分、管理不科学，效率不会提高。

## Worked Example
1998年首场记者会，法国《世界报》记者问：韩国大财团纷纷垮台，是否会影响中国国企改革、是否会放慢速度？
回答结构：
1. 不评论韩国企业个案，但强调要吸取亚洲金融危机教训。
2. 明确不改节奏：3年内使大多数国有大中型亏损企业摆脱困境"完全能够实现"。
3. 校正统计口径：亏损面49%是按企业个数算的，中国有7.9万个工业企业，很多只有几十人；500个特大型国企贡献全国税收和利润的85%，亏损面只有10%（约50家）。
4. 得出总体判断：从总体看，三年脱困目标可以实现。
这段答问示范了"先定调—再拆数据—再给结论"的典型结构，也说明国企改革叙事必须同时管理"总量"和"结构"两个视角。

## Key Takeaways
1. 国企改革是"阶段性脱困 + 长期制度建设"两层目标，不能混为一谈。
2. 统计口径会决定结论；先问"按个数还是按税利"。
3. 股份制是经营形式，不等于私有化；控股权只保留在极少数关键企业。
4. 人员分流必须与再就业、社保同步，否则改革不可持续。
5. 大企业做强、小企业放活，不能用同一套办法。
6. 亏损的原因要分类诊断：重复建设、债务、冗员、机制，各有对策。
