# Chapter 1: 日常与自杀计划——用秩序包裹死亡

## Core Idea
欧维的"死"不是戏剧性的绝望，而是一项待办事项：量尺寸、选钻头、铺防护膜、写信、付清账单。他用工程化的方式安排死亡，恰如他用巡逻、煮两杯咖啡、检查门把手来安排生活。小说真正的张力不在"他会不会死"，而在于一个把世界简化为规则的人，如何被一系列具体的"麻烦"重新拉回关系之中。

## Frameworks Introduced
- **秩序是哀悼的容器**：当悲伤无法言说，人会把不可控的情感转成可控的动作。巡逻、上油、数车牌，都是"我还在"的证据。
- **被需要先于被理解**：邻居不是说服欧维活下去，而是让他"没时间死"。意义通过任务进入生活。
- **打断即连接**：每一次自杀被打断，表面是冒犯，实质是关系在敲门。
- **规则的双重性**：规则既保护欧维免受混乱，也把他关在孤独里；成长不是放弃规则，而是决定为谁破例。

## Key Concepts
- **巡逻**：每天六点差一刻起床，检查标牌、车库、垃圾房、访客停车；不是职责，是存在的仪式。
- **两杯咖啡**：索雅死后仍煮两人份，"一杯一勺，外加一勺养壶"。
- **钩子**：要在天花板正中央装一个"拆房子时最后屹立"的钩子，用于上吊。
- **防护膜**：上吊前铺满地板，不是怕血，而是怕来看房的"公子哥"穿着鞋糟蹋地板。
- **萨博**：身份、忠诚与可计算世界的象征。
- **白衬衫**：官僚、制度性冷漠的统称。
- **猫**：半截尾巴、一只耳朵，和欧维一样"不成样子"，成为他照顾能力的第一个练习对象。
- **帕尔瓦娜**：伊朗孕妇，不请自来的邻居，用请求而非道理攻破欧维的边界。
- **"这不是旅馆"**：欧维的口头禅，也是他最终反复破例的地方。

## Mental Models
- **Use 巡逻 when 悲伤无处安放** — 把不可控的情绪转成一个可完成、可重复、可检查的动作，让身体先撑过今天。
- **Use 规则 when 世界失控** — 规则不是目的，而是降低不确定性的脚手架；先有稳定节奏，再谈改变。
- **Use 打断 when 想退出关系或生命** — 不要把"被打断"只当冒犯；它可能是别人递来的、笨拙的挽留。
- **Use 具体任务 when 情绪过载** — 修水龙头、换螺丝、给暖气通风，比"想开点"更能恢复掌控感。

## Anti-patterns
- **把原则当人格**：欧维把"不交三克朗增值税"当成自我，结果原则越硬，人越孤。
- **用愤怒替代悲伤**：愤怒有力量，悲伤没有；但愤怒会把想靠近的人推开。
- **等"准备好"再活**：欧维把死亡排进日程，却把生活一直推迟。
- **把帮助当施舍**：欧维拒绝一切"被可怜"，也因此拒绝了很多连接。
- **用仪式替代关系**：两杯咖啡是爱，但只煮咖啡不见人，就变成了牢。

## Worked Example
索雅死后第六个月，欧维决定上吊。他穿上西装，铺好塑料防护膜，量了天花板，换了四次钻头，在正中央画了个叉。他把索雅的照片翻向储藏室——"她需要看到些生气"，但又不想让她看着自己动手。门铃响到第三次，他放下电钻去开门：帕尔瓦娜和帕特里克站在门口，递上一盒"波斯蛋糕"，为倒拖斗撞坏花坛道谢。欧维说"成年人本来就该会倒拖斗"，准备关门；帕尔瓦娜把脚踩在门槛上，报出自己的名字。欧维收下蛋糕，关上门，回到客厅，看着钩子，决定"再等个把小时"。

这个场景确立了全书机制：**死亡计划被具体的人、具体的食物、具体的请求一次次推迟**。欧维不是被说服的，他是被"占用"的。

## Key Takeaways
1. 仪式既能承载悲伤，也能囚禁生者；区别在于仪式里有没有别人。
2. 想帮助一个封闭的人，少讲道理，多给一个他能完成的具体任务。
3. "被打断"是关系最原始的形态；不要急着把它定义为冒犯。
4. 原则值得坚持，但要知道自己是在守护人，还是在守护自己的正确。
5. 一个人重新活过来，往往不是想通了，而是被需要了。
