# Chapter 3: 金融改革与风险处置

## Core Idea
金融改革的顺序是"监管能力先行、经常项目先开放、资本项目后开放"；处置金融风险要打破刚性兑付、坚持国际惯例，但要用重组、注资、债转股避免系统性连锁反应。

## Frameworks Introduced
- **"中央银行强化监管、商业银行自主经营"**
  - 央行管规则、管风险、管系统性稳定；商业银行自主放贷、自负盈亏。
  - 当银行既承担政策性任务又追求利润时，先拆职能：政策性业务交给政策性银行，商业业务按市场规则办。
- **人民币可兑换的"两步走"**
  - 第一步：经常项目可自由兑换（已实现）。
  - 第二步：资本项目可自由兑换，必须等中央银行监管能力达到后再实行。
  - 当被问"何时完全自由化"时，用"能力条件"而非"日期承诺"回答。
- **广信破产：打破刚性兑付**
  - 原则：政府不为金融企业偿还非政府担保的债务；债权人必须做风险分析。
  - 同时强调"不要破出甜头"：破产要合法、合情、合理，不能变成逃债工具。
  - 处置工具箱：资产重组、注资、债权变股权、按国际惯例谈判。
  - 当个别金融机构资不抵债时，用"个案处置 + 明确不兜底"切断道德风险，同时用重组工具防止挤兑蔓延。
- **不良贷款剥离 + 资产管理公司**
  - 借鉴美国RTC经验，把不良贷款从商业银行剥离，成立资产管理公司专业处置。
  - 当银行不良率高、信贷功能受阻时，先剥离存量，再改革增量，恢复银行放贷能力。
- **证券市场"发展快、成绩大、很不规范"**
  - 不因为问题多就否定市场，也不因为发展快就回避规范。
  - 当市场被指"像赌场"时，先承认不规范，再讲规范方向：透明度、信息披露、投资者保护、引进专业人才。

## Key Concepts
- **经常项目可兑换**：贸易、服务等日常外汇收支可自由兑换。
- **资本项目可兑换**：投资、借贷等资本流动可自由兑换，风险更高。
- **不良贷款**：银行收不回的贷款；高企会吞噬资本金、抑制放贷。
- **资产管理公司**：专门收购、管理、处置不良资产的机构。
- **道德风险**：政府兜底会让金融机构和债权人忽视风险。
- **联系汇率制**：香港港元与美元挂钩的制度（详见Ch 7）。
- **金融分业监管**：银行、证券、保险按业务分别监管。
- **外汇储备**：央行持有的对外支付能力；书中以1450亿美元等具体数字回应偿付能力质疑。

## Mental Models
- 当危机中有人建议人民币贬值时，用"区域责任 + 信心稳定 + 产业升级"三重理由拒绝竞争性贬值。
- 当金融机构破产引发恐慌时，区分"该不该救"与"怎么处置"：不救非担保债务，但用重组工具防止系统性传染。
- 当被问资本项目开放时间表时，用"监管能力"作为闸门条件，而不是给一个政治日期。
- 当银行不良率高时，先剥离存量、再改革治理，不能靠继续放贷掩盖。
- 当股市问题暴露时，用"在规范中发展、在发展中规范"避免要么放任、要么关停。

## Anti-patterns
- **过快开放资本项目**：监管能力跟不上，热钱大进大出，重演亚洲金融危机。
- **政府无条件兜底金融企业**：激励冒险，最终由财政和纳税人承担。
- **破产破出甜头**：企业借破产逃废债务，破坏信用体系。
- **用行政命令替代金融监管**：不按风险定价、不按规则处置，问题越拖越大。
- **只重融资、不重规范**：股市成为圈钱工具，失去投资者信任。

## Worked Example
1999年人大记者会，日本记者问：广东国际信托投资公司（广信）倒闭损害了外国金融机构对中国的信任，如何评论？
回答结构：
1. 定性：广信破产是中国金融改革过程中的"个别事件"，不是金融危机。
2. 原则：中国政府不会为一个金融企业还债，除非债务由各级政府担保；外国银行放贷必须做风险分析。
3. 能力：中国外汇储备1450亿美元、国际收支平衡，完全有能力偿还"应该由政府偿还"的债务。
4. 边界：破产要合法、合情、合理，不能"破出甜头"；债权人不要逼债，逼急了只能破产。
5. 出路：按国际惯例谈，采取资产重组、注资、债权变股权等办法，债务可以偿还，企业也不必破产。
这段答问把"不兜底"的硬原则与"防传染"的软安排同时讲清，是风险处置沟通的范本。

## Key Takeaways
1. 金融开放是顺序问题：先经常项目、后资本项目，先监管能力、后自由兑换。
2. 不兜底不是不管，而是用重组工具处置，避免系统性风险。
3. 破产必须防止道德风险，不能让逃债变成理性选择。
4. 银行改革要同时处理存量不良和增量治理。
5. 资本市场要在规范中发展，透明度是信任的基础。
6. 监管人才和监管能力是开放的前提，可以引进外部专业人才。
