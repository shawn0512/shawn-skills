# Chapter 3: 国家与革命——1871年巴黎公社的经验

## Core Idea
巴黎公社提供了无产阶级打碎旧国家机器、建立新型国家的具体形式和经验。

## Frameworks Introduced
- **公社形式**：无产阶级专政的具体组织形式
  - When to use: 设计新型民主制度时
  - How: 一切公职人员选举产生、可随时撤换、薪金不超过工人工资

- **无产阶级专政**：从资本主义到共产主义的过渡时期的国家形式
  - When to use: 分析过渡时期的政治问题时
  - How: 以工人阶级的政治统治为基础，镇压剥削者反抗

## Key Concepts
- **巴黎公社**：无产阶级专政的第一次尝试
- **公社式民主**：选举制、撤换制、工人工资制
- **无产阶级专政**：过渡时期的必然国家形式
- **民主的扩展**：从资产阶级民主到无产阶级民主的质变

## Mental Models
- 公社 = 终于发现的使劳动在经济上获得解放的政治形式
- 民主的扩展是质变：多数人的民主取代少数人的民主

## Anti-patterns
- **照搬旧民主**：用资产阶级民主的框架理解无产阶级民主
- **忽视公社教训**：忘记马克思对公社经验的总结

## Key Takeaways
1. 巴黎公社是无产阶级打碎旧国家机器的第一次实践
2. 公社的核心措施：选举制、撤换制、工人工资制
3. 无产阶级专政是过渡时期的必然形式
4. 马克思高度评价公社的首创精神
5. 公社的经验证明了打碎国家机器的必要性
