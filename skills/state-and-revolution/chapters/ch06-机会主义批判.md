# Chapter 6: 马克思主义被机会主义者庸俗化

## Core Idea
列宁系统批判了考茨基、普列汉诺夫等人对马克思主义国家学说的歪曲，揭示了机会主义在无产阶级革命问题上的背叛。

## Frameworks Introduced
- **机会主义批判框架**：
  - 维度1：是否承认暴力革命的必要性
  - 维度2：是否承认必须打碎旧国家机器
  - 维度3：如何理解无产阶级专政
  - When to use: 识别和批判各种机会主义倾向
  - How: 从三个维度审视政治立场

- **考茨基主义分析**：在理论上不否认马克思主义，但在实践中"忘记"革命内容
  - When to use: 识别伪装成马克思主义的机会主义
  - How: 看他是否"忘记"了革命的最核心内容

## Key Concepts
- **考茨基主义**：形式上坚持马克思主义，实质上阉割革命灵魂
- **普列汉诺夫**：俄国机会主义的理论代表
- **社会沙文主义**：口头上的社会主义，实际上的沙文主义
- **庸俗化**：把革命学说变为资产阶级可以接受的东西

## Mental Models
- 识别机会主义的关键：看他"忘记"了什么（而非说了什么）
- "在理论上承认、实践中忘记"是考茨基主义的典型手法

## Anti-patterns
- **考茨基式背叛**：口头上承认马克思主义，实践中否定暴力革命
- **形式主义的马克思主义**：只在口头上坚持，在关键问题上后退

## Key Takeaways
1. 考茨基主义是马克思主义最危险的敌人
2. 机会主义的特点是"在理论上承认，在实践中忘记"
3. 普列汉诺夫在革命问题上的立场是错误的
4. 必须同机会主义进行彻底的斗争
5. 第二国际的破产证明了机会主义的破产
