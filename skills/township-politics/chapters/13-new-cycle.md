# Chapter 13: 新的年轮

## Core Idea
2004年的惠农政策——中央一号文件、粮食直补、保护价、取消农业税——一夜之间改变了土地的相对价值。过去弃之不及的承包地变成值得争夺的资产，于是爆发“争地风潮”。土地纠纷不是单纯的法律问题，而是**政策周期、比较利益和村庄成员权观念**共同作用的结果。林书记能写出漂亮的分类与对策，基层真正解决问题却往往靠“乡情”而非法律。

## Frameworks Introduced

- **政策周期与土地价值反转** — 税负重、粮价低时土地是负担，农民弃耕、转包、外迁；税负取消、补贴增加时土地变资产，外迁者回来索地。
- **争地六类型** — 权属模糊型、转包毁约型、开发占地型、代耕索地型、政策占压型、综合交织型；分类有助汇报，不能替代逐案处理。
- **“一套法规备查、一组规定答疑、一剂良方对症”** — 林书记的对策：专班负责、法规备查、规定答疑、分类施治；形式完备，实践依赖人的裁量。
- **依法明是非，按乡情了事** — 先用法律讲清是非，再依熟人社会长期相处需要促成妥协；“回避法律的策略”是乡村司法常态。
- **灰色势力作为治理中介** — “道上的伢们”介入工程与纠纷，政府不愿招惹，只能承认其承包或协调地位。
- **“耗油”与“就范”** — 政府用拖延、冷处理消耗上访者；对方耗不起时间金钱，最终接受地方条件。

## Key Concepts

- **争地风潮** — 政策转向后外迁农民集中回村索要承包地。
- **经营权证 / 二轮承包** — 1998—1999年确权的承包关系，是法律上的主要依据。
- **权属模糊** — “有权无证”“有证无权”“一地多权”。
- **转包毁约 / 代耕索地** — 土地升值后单方毁约，或回来索要当初请人代耕的地。
- **乡情** — 熟人社会中长期相处、互留余地的规范。
- **“糊涂官对糊涂百姓”** — 平时不按程序办事，出事时谁也说不清。
- **“道上的伢们”** — 有灰色背景、关系复杂、不好惹的地方势力。

## Mental Models

- **Use 政策周期 when** 解释土地为何从“包袱”变成“争夺对象”；不要只看法律文本。
- **Use 争地六类型 when** 面对一批土地纠纷，先分类再判断哪些能依法裁断、哪些只能协商。
- **Use 依法明是非/按乡情了事 when** 法律判断清楚但执行会破坏长期关系；先讲法，再找台阶。
- **Use 灰色中介 when** 正式治理能力不足，地方势力却能“摆平”工程或纠纷；承认其地位往往比对抗便宜。
- **Use 耗油 when** 对手的时间成本远高于你，拖延本身就是议价手段。

## Anti-patterns

- 以为政策文件一下发，土地关系就自动清晰。二轮承包的手续漏洞会在十年后集中爆发。
- 以为分类方案等于解决方案。“一剂良方对症”在汇报中成立，在田间地头往往失灵。

## Worked Example

大陈村李国辉1993年外出，把田地交给他人耕种，1999年二轮承包时村里没有通知他回来确认，土地上了别人的经营权证。2004年土地升值，他回村要地，与现承包户发生冲突。镇里按林书记的方案组织调处专班，司法所冯所长先讲法律：以二轮承包和经营权证为准，李国辉多年未耕种、未缴税，村组有权收回重新发包。

李国辉不服：“为何二轮承包时村里不通知我们回来？”“计划生育我一样不在家，为何又找得到我们？”这些问题把村书记问住，暴露了程序漏洞。冯所长承认他说的可能是事实，但“现在证据就是土地上了别人的经营权证”。调解一上午无果。

冯所长私下说：“你可以坚持法律，但最后处理还得按照乡情来。在乡下，合不合法不是最要紧的，要紧的是能否化解矛盾。”他预计只能动员其他农户各让一点地。后来果然如此：其他农户放弃部分权利，归还部分土地，李国辉见好就收。纠纷在法律之外、以“乡情”方式化解。

同一年，潭水湾清淤工程展示了另一种解决方式。施工方给六千元，大陈村想接，但水面承包人陈伟业——“道上的伢们”——直接要接工程。副镇长宋正良不愿招惹，答应；村书记钱秉贵也退让。陈伟业派小兄弟来谈，最终价格高得出奇，宋正良也弄不清陈与施工队之间做了什么交易。正式程序还在，决定结果的是灰色势力和关系。

## Key Takeaways

1. 土地纠纷的爆发，往往是政策周期反转了土地价值，而非农民突然“懂法”或“刁蛮”。
2. 法律提供是非框架，却不能提供熟人社会可执行的解决方案。
3. “依法明是非、按乡情了事”不是腐败，而是长期关系约束下的务实选择。
4. 分类和对策方案有助向上汇报，真正调处依赖具体的人、关系和台阶。
5. 灰色势力填补正式治理的空隙，政府往往选择承认而非对抗。
6. “耗油”是时间战：谁更耗得起，谁就能把条件压向自己。
