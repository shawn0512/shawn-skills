# Chapter 8: 僵持

## Core Idea
当正式规则无法裁断、双方又都不愿退让时，乡村纠纷进入“僵持”：叶桦用法律和上级批示向政府施压，四组农民签字后又反悔、拦推土机，陈同年的土地案在法院和村委之间被踢来踢去。僵持的根源不是缺少规则，而是**规则太多、彼此冲突，且缺乏可执行的裁决者**。最终解决问题的，往往不是判决，而是政治压力、时间消耗和新的利益交换。

## Frameworks Introduced

- **依法博弈 / 以法抗争** — 弱者援引法律、政策、上级文件和媒体，把自己的诉求包装成“合法权利”，迫使地方政府在合法性压力下回应。
- **上访 vs 诉讼** — 诉讼需要证据、成本和时间，且法院可能回避敏感权属问题；上访能把纠纷“政治化”，启动稳定考核和上级问责，因而更受农民青睐。
- **法律作为治理资源** — 政府用合同、公证、经营权证把行政行为合法化；农民则用法律话语争取上级和舆论支持。法律不是中立的裁判，而是双方争夺的资源。
- **村级调解的衰败** — 村组干部怕惹麻烦、怕得罪人、怕承担后果，遇到“烂事”就推给法院；法院又因证据不足或权属不清推回村里，形成“踢皮球”。
- **“石头飞上天还是要落地”** — 林靖南的经典判断：无论闹到多高，事情最终还要由基层解决；因此政府不必害怕上访，只要占住“理”并稳住局面。

## Key Concepts

- **僵持** — 双方都不让步、也无法强制对方服从的持续对峙。
- **反悔 / 翻盘** — 已签字农户在比较后要求重新谈判。
- **拦推土机 / 阻工** — 农民最直接的施压方式。
- **权属模糊** — 二轮承包、经营权证、实际耕种面积、历史转让之间的不一致。
- **断不清的土地案** — 法院无法认定权属，只能回避核心问题。
- **代理人的双重利益** — 贺志伟既代表叶桦，又想继续与政府合作。
- **对话会** — 政府与农民代表面对面对话，既是谈判，也是表演。

## Mental Models

- **Use 依法博弈 when** 弱者掌握法律或政策文本，能把地方问题上升为合法性、投资环境或上级问责问题。
- **Use 上访 vs 诉讼 when** 分析农民为什么宁愿上访也不打官司：成本、证据、官官相护、政治化收益。
- **Use 踢皮球 when** 村、镇、法院都不愿承担裁决责任，纠纷被反复推回。
- **Use “石头落地” when** 判断政府为何不怕上访：最终处理权仍在基层，上级只会加压不会替代。

## Anti-patterns

- 以为法院能解决所有土地权属纠纷。乡村土地的权利链条常常不完整，法院只能回避或发回。
- 以为签字就代表同意。签字可能是被缠磨、被欺骗、被面子压力下的策略性行为。
- 以为上访者不懂法。很多上访者恰恰是熟练使用法律和政策话语的“特别能战斗”的农民。
- 以为政府怕上访就会无条件让步。政府会在“不出事”和“不开口子”之间计算。

## Worked Example

叶桦收到政府“合同无效、限期迁让”的来函后，没有选择沉默，而是从美国连发两信，援引《土地管理法》《农村土地承包法》《台商投资保护条例》，把信抄送省市区各级、台办、侨办、媒体和律师，使用“官争民利”“官逼民怨”等话语。政府则通过代理人贺志伟谈补偿。贺志伟既想替叶桦争到更多，又想继续在小镇拿地，于是不断向政府表示“协助政府工作”，把叶桦的底价从三百万、两百万一路压到八十七万，再逐步评估、砍价。

四组农民则在签字后反悔。他们认为政府不丈量面积、一次性补偿太低，于是拦住推土机，要求“土地占到哪里补到哪里”。林靖南亲自与六名代表对话，承认“矛盾集中到一点还是利益问题”，但坚持四千五百元一亩、承诺以后地价涨了再补，并用农业税全免、粮食救济等方案解决泵站拆除的善后。对话没有彻底说服农民，但把冲突重新纳入可控的谈判轨道。

陈同年的案子则展示了另一种僵持：他强行耙了陈向辉已下种的秧田，反被起诉；法院依据经营权证承认部分转让，却回避了一点九斗水田的归属；村里不愿再调解，说“既然选择了法律，就应该坚持在这条路上走下去”。陈同年从原告变被告，又从被告变原告，土地仍在对方手里，问题回到起点。

## Key Takeaways

1. 僵持的产生，往往是因为正式规则之间相互冲突，且没有权威的裁决者。
2. 法律和政治是两种可互换的博弈资源：强者用法律合法化，弱者用政治压力反制。
3. 上访之所以流行，是因为它比诉讼更便宜、更快、更能启动上级问责。
4. 签字不是终点；比较、反悔和翻盘是乡村谈判的常态。
5. 村、镇、法院之间的“踢皮球”，使许多纠纷长期悬置。
6. “石头飞上天还是要落地”揭示了基层治理的底气，也揭示了它的局限。
