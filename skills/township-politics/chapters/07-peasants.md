# Chapter 7: “可嫌”的农民

## Core Idea
基层干部常说“农民既可怜又可嫌”。这不是简单的道德评价，而是对农民**弱与强并存**的经验概括：农民在制度、土地权利和市场地位上是弱者；但在具体博弈中，他们又能利用政策空隙、法不责众、阻工、上访、种房和灰色关系“反弱为强”。理解基层政治，必须同时看到这两面，而不能只把农民当作被动的受害者或道德化的“刁民”。

## Frameworks Introduced

- **弱者的武器** — 农民用不合作、拖延、违规、钻空子、耍赖、阻工、上访等低成本方式维护利益；这些行为弥散、无组织，却能侵蚀规则。
- **反弱为强 / 强弱错置** — 弱者通过制造“政府不敢出事”的场景，把自己的弱势转化为谈判筹码；政府则在“稳定压倒一切”的约束下让步。
- **法不责众与“事实婚姻”** — 当违规行为形成规模、成为既成事实，政府因执法成本、社会稳定和舆论压力而不得不承认或补办手续。
- **灰色秩序 / 江湖规则** — 在正式执法能力不足的地方，有背景的“道上伢们”用暴力威胁、关系网络和江湖规矩填补秩序真空；政府有时回避、有时借力。

## Key Concepts

- **可怜 / 可嫌** — 干部对农民的双重评价：值得同情，又难以打交道。
- **刁民** — 干部对利用政策空隙、有意违规博利者的贬称；作者把它当作价值中立的分析概念。
- **种房** — 在待征地上抢建、加层、扩院，赌开发补偿。
- **违建** — 未经批准的建房；政府缺乏执法权，只能劝阻、推墙、拖延。
- **事实婚姻** — 违规建筑存在久了，政府最终不得不承认或补办手续。
- **道上的伢们** — 有江湖背景、靠关系和暴力潜势做事的人。
- **扯横皮** — 农民对自身“不讲理”博弈方式的自我评价。
- **弱者的武器** — 日常形式的反抗，不是革命，而是让规则部分失效。

## Mental Models

- **Use 弱者的武器 when** 弱势一方无法正面改变规则，却能用拖延、违规、不合作提高对方的治理成本。
- **Use 法不责众 when** 违规行为已经成片、成规模，政府强制拆除或全面追责的成本过高。
- **Use 反弱为强 when** 政府越怕出事，弱势方越能用“闹大”“上访”“喝药”等姿态换取让步。
- **Use 灰色秩序 when** 正式执法缺位，而有背景的中间人能用非正式规则“摆平”事情。

## Anti-patterns

- 把农民道德化为单纯的受害者。这会忽略其策略性、逐利性和内部差异。
- 把农民道德化为“刁民”。这会忽略其行为背后的制度不公和生存理性。
- 以为政府有正式权力就一定能执行。执法权、经费、人员和维稳约束都可能使正式权力悬空。
- 以为“种房”只是愚昧或贪婪。它是对补偿规则、执法能力和未来不确定性的理性计算。
- 对灰色力量一味回避或一味打击。基层往往在“用不上、惹不起、离不开”之间摇摆。

## Worked Example

小陈村传出快速铁路将经过的消息后，农户纷纷在旧房上加层、向前后院落扩张，甚至把房子建到耕地里。补偿标准是每平方米两百元，而建房成本只有一百多元，于是“种粮不如种房”。农民并非不知道违建可能不补偿，但他们赌的是：一旦形成规模，政府不可能全部强拆。

城管所所长孙福临天天带人下村，看到刚砌的墙就用木棒捅、用脚踹，责令补报；但他坦言，城管所经费无着、人员散失，自己没有执法权，“除了天天下来转，威吓一下，我也没有其他办法”。村干部则大多睁一只眼闭一只眼，甚至给亲戚通风报信。主管城建的宋正良说，强拆需要区里组织公安、城管、土管几百人，“没有区里的布置，镇里也不愿意找这种麻烦”。

几年后，这些房子住进了人、形成了社区，政府再要拆除就更难，只能甄别“可批”与“不可批”，对多数补办手续。农民用“法不责众”制造了“事实婚姻”，把违规变成了既成事实。作者由此指出：农民的“刁蛮”背后，是长期缺乏公正表达渠道和权利保障的结构性处境。

## Key Takeaways

1. 农民的弱与强不是矛盾，而是同一结构的两面。
2. “弱者的武器”之所以有效，是因为正式治理存在执法、经费和合法性缺口。
3. “法不责众”把个体违规转化为集体既成事实，迫使政府承认。
4. 灰色力量是正式秩序不足时的替代品，既维持局部秩序，也侵蚀公共权威。
5. 用“可怜”或“可嫌”单一标签理解农民，都会失去对其行动逻辑的把握。
6. 农民的违规行为往往是对不合理前提的理性回应，而不只是道德问题。
