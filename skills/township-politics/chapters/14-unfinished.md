# Chapter 14: 未完的结局

## Core Idea
一年半的田野结束，故事却没有结束。大陈村的藠头成功，前王村颗粒无收；陈同年的土地案仍悬着；征地因国家政策收紧而冻结；石场业主还在等待；取消农业税后干部突然不知道“还能做什么”；迎检依旧。**基层治理没有终局，只有一轮又一轮的未完成**。成败也不是技术或市场单独决定的，而是政府的注意力、资源投入和风险分配共同塑造的。

## Frameworks Introduced

- **试点成败的政治分配** — 同样项目，大陈成为“扶强”的样板，前王成为失败代价的承担者；成败被用来证明或否定政府主导的农调模式。
- **“政府搞一次农调就失败一次”的宿命** — 政府替代市场做种植决策，承担种子、技术、销售和风险，农民只出地力和工；失败后责任回流政府。
- **后税费时代的职能真空** — 取消农业税后，干部从“收钱”中解放，却失去工作重心；新定位是“拉项目、跑钱”、招商引资。
- **迎检的文本生产** — 计生检查重点不是服务本身，而是账、表、卡、册的规范与数据；干部还要让对象户“记得住”被问的事实。
- **未完成性** — 许多冲突只是被搁置、冻结或推迟，不是被解决；研究只能记录过程，不能虚构终局。

## Key Concepts

- **喜与忧** — 大陈成功、前王失败，同一政策的两副面孔。
- **颗粒无收 / 白地** — 前王百余亩藠头全毁，土地重新翻耕。
- **500元劳务费 / 300元赔偿** — 合同承诺与农民实际损失之间的落差。
- **征地冻结** — 国家严控土地审批，开发商签了合同也办不下手续。
- **“雷声大雨点小”** — 看地的多，谈成的少。
- **无税时代** — 2004年取消农业税后的新常态。
- **“拉项目、跑钱”** — 后税费时代干部的核心能力。
- **文本抽象化** — 把日常服务转化为可检查的表格和数据。

## Mental Models

- **Use 试点成败的政治分配 when** 分析同一项目为何一村成功、一村失败：资源、注意力、干部配置和风险承担都不同。
- **Use 政府主导农调的宿命 when** 政府替农民决定种什么、包技术包销售；失败时政府必然成为索赔对象。
- **Use 后税费时代的职能真空 when** 一项核心任务消失后，组织需要重新寻找合法性来源和工作重心。
- **Use 迎检的文本生产 when** 上级检查的是可复现的文本，而非已发生的服务；准备重点在台账和受访人记忆。
- **Use 未完成性 when** 期待一个干净结局；基层更多是搁置、冻结、拖延和再循环。

## Anti-patterns

- 以为成功试点可以复制。大陈依赖持续资源倾斜和干部盯守，前王没有同等条件。
- 以为取消农业税就解决了基层治理问题。它解决了征收冲突，却制造了职能真空和项目竞争。
- 以为检查等于工作。检查考核的是文本抽象化能力，可能与实际服务脱节。

## Worked Example

大陈村的藠头长势良好，6月收购价每斤六毛，一亩获利至少千元，远高于种粮。镇政府决定把大部分未收的藠头留作种子，继续扶植大陈。这是“扶强不扶弱”的正面版本：资源投向已显示成绩的村，确保样板可复制、可汇报。

前王村则是另一面。百余亩藠头全军覆没，地里只剩翻耕过的白地。农民说种子有问题、没有技术指导，打了农药后再没见过藠头生长。农民亏了一年工，君山教办亏了种子农药，镇政府预支了每亩一百元工钱和机耕费，村里赔了尚未收的花生芝麻，还一家家送种子、盯下地。农民找政府扯皮，要求按一季油菜每亩至少赔三百元；他们知道完全无收时再要五百元劳务费不现实，于是主动降低要价。

镇村干部窝火，因为当初是政府和村里“求着、哄着、惯着”农民搞的。失败不仅是一季作物，更是对“政府主导农业结构调整”合法性的又一次打击。作者称之为“宿命”：政府搞一次农调就失败一次，但还要继续搞，因为政绩、项目和上级检查需要可见的农业亮点。

取消农业税后，干部们长舒一口气：“再也不用昧良心、狠心肠地从农民家里撮谷背粮。”但紧接着是新的迷茫：不收税，干部做什么？武镇长的答案是“拉项目、跑钱”——有能耐、有板眼，就看能不能给村里拉来项目、跑来钱；搞好服务只是低层次要求。年轻干部则花大量时间维系区镇关系，争取支农项目。与此同时，计生迎检照旧：干部准备账、表、卡、册，还要让对象户记住随访时间、次数和内容，因为检查人员会入户核实。

## Key Takeaways

1. 同一政策可以在一村制造样板，在另一村制造废墟；差别在资源、注意力和风险分配。
2. 政府主导的农业调整，失败时政府无法退场，因为它既是发起者也是担保人。
3. 取消农业税解决了“要钱”的冲突，却留下“干什么”的真空。
4. 后税费时代的干部能力，越来越体现为“拉项目、跑钱”的关系能力。
5. 迎检生产可检查的文本，不是可验证的服务；两者可能脱节。
6. 基层没有干净结局；冻结、搁置和再循环本身就是治理的一部分。
