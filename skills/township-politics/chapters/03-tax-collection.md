# Chapter 3: 要钱是孙子，无钱是羔羊

## Core Idea
税费改革本想减轻农民负担、缓和干群关系，却在城郊乡镇制造了一个意外后果：**征收更难了**。上级同时下达“不得强制征收”的高压线和“任务一分不能少”的硬指标，乡镇失去了强制手段，却保留了完成任务的连带责任。于是，征收从行政强制变成一场以人情、缠磨、垫税和关系协调为武器的持久战。

## Frameworks Introduced

- **“要钱是孙子，欠钱是大爷”** — 当国家自我冻结暴力潜势、又坚持征收指标时，制度上的强者在日常互动中变成弱者；征收者必须自我矮化、说好话、套近乎。
- **责任与权力脱钩** — 征收主体转到财政所，乡镇和村仍承担考核责任；有责无权，任务只能靠垫税、借税、买税和人情完成。
- **垫税—协税—引税链条** — 干部先垫钱完成进度；税源不足时到外地“协调”税源，或通过关系把税“引”进来；上级默许，因为财政增长也是上级政绩。
- **软性征收** — 在不能强制的前提下，使用蹲守、反复上门、找贩子、亲情施压、给面子、分期付款、以物抵税等非正式手段。

## Key Concepts

- **税赋悬空** — 农民不签字、土地抛荒或有税无地，导致任务无法落地。
- **黑土地 / 黑面积** — 未上报、未纳税但实际耕种的土地；开发时又成为补偿争议焦点。
- **计税面积 vs 实种面积** — 前者是税改认定的面积，后者是农民实际耕种面积，两者长期不一致。
- **垫税** — 干部或村集体先出钱替农户完成征收进度。
- **协税 / 引税 / 买税** — 通过关系、财政返还或跨区操作完成税收任务。
- **进度表 / 排名** — 用公开比较制造面子和竞争压力。
- **连坐制** — 镇、村、财政所干部共同承担征收责任。
- **“打不还手，骂不还口，有钱就收，无钱就走”** — 税改后征收纪律的顺口溜。

## Mental Models

- **Use 责任—权力脱钩 when** 你看到基层被要求完成某项任务，却被剥夺了完成任务所需的手段。
- **Use 软性征收 when** 强制被禁止、指标仍存在，征收者开始依赖关系、面子和时间消耗。
- **Use 垫税 when** 报表上的进度很好，但农户实际缴款很少；数字是干部的钱堆出来的。
- **Use 协税 when** 本地税源不足，但上级排名压力很大；税收可以在地区之间“协调”。

## Anti-patterns

- 以为减负会自动提高纳税意愿。负担下降与缴纳意愿之间没有线性关系，攀比和不公平感可能更强。
- 以为禁止强制征收就消除了基层的强制。强制转化为连带责任、垫税、人情压力和选择性执法。
- 把征收进度当作真实征收率。它可能包含干部垫款、借税、买税和重复计算。
- 用“刁民”道德化农民的抗税。抗税往往是对面积不公、政策矛盾和比较差距的理性反应。

## Worked Example

秦家畈村四组在镇街范围内，多数是兼业户。征收第一天，临街商户虽然抱怨“这么早收”，但“早缴迟不缴，反正也是缴”，很快掏钱。拐进田间后，情形立刻不同：农户在忙农活，见干部带陌生人要钱，便嚷“这么早收么子钱，冇，过两天再来”。

在一户曹姓人家，税费七十三元，女主人说谷子没卖、没有钱。专管员毕华英说上月来过，不能总等卖谷子；妇女主任郭云霞提出找贩子上门收谷，女人又改口说“没有四十二元不卖”。郭云霞事后承认，她并不真能找到贩子，“这样讲，是怕她再拖延”。另一户朱姓人家则直接拒缴，说地早已给了别人，“我一分钱都不把”。

这些场景说明：征收不是简单的“给不给”，而是围绕时间、面子、价格、面积和历史旧账的连续博弈。村干部和专管员能用的，只有反复上门、软磨、找台阶和制造一点压力。

## Key Takeaways

1. 税费改革的核心悖论是：减轻负担的政策同时削弱了基层的征收能力。
2. 当强制被禁止而指标不变，征收必然转向关系、人情、垫税和数字操作。
3. “有责无权”是理解基层干部无力感的关键结构。
4. 农民的抗税行为有分层：真穷、攀比、面积不公、政策空隙、策略性拖欠。
5. 征收进度是政治数字，不等于农户实际负担或政府真实汲取能力。
6. 财政压力会把乡镇推向开发，而开发又制造新的土地纠纷。
