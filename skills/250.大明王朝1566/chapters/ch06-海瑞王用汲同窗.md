# Chapter 6: 海瑞王用汲同窗 (Hai Rui & Wang Yongji — the Newcomers Meet)

## Core Idea
新任淳安知县海瑞与新任建德知县王用汲在臬司衙门右门房相遇，以"幸会"、"贱字润莲"、"刚峰兄海笔架"等极简敬词建立最初的同僚识别；体制用门房等级区分官阶，两位廉吏用识别暗号完成非正式结盟。

## Frameworks Introduced
- **门房等级制**（Gatehouse Hierarchy）— 同一衙门分左右门房，右边品级低；海瑞被领进右门房，确认他的起点位置。这是朝廷对官阶的物理编码。
- **笔架与字号识别**（Brush-Rack Identification）— "海笔架"是海瑞的字形绰号（其官服展脚幞头像笔架），"刚峰"是他的字号；识别绰号就是识别圈内人。绰号是入场券。
- **同科、同窗、同引荐人**（Three-Link Network Test）— 王用汲自报"谭纶谭子理和我是同科好友"，海瑞立刻接"润莲兄也是谭子理举荐的吧"。每一次自我披露都同时是身份验证。
- **幸会的话术密度**（Density of Courtesy）— 短短几句对话中，两人已交换：籍贯、职务、字号、座主、同窗关系——这是高密度信任测试。

## Key Concepts
- 海瑞（Hai Rui, magistrate of Chun'an）
- 王用汲（Wang Yongji, magistrate of Jiande）
- 海笔架（"Brush-rack Hai" — 海瑞的绰号）
- 刚峰兄（"Brother Gangfeng" — 海瑞的字）
- 润莲（"Brother Runlian" — 王用汲的字）
- 谭子理（Tan Zili, i.e., 谭纶 Tan Lun）
- 臬司衙门（Provincial judicial yamen）
- 右门房（Lower-rank gatehouse）
- 书办（Clerk）
- 同科好友（Friends from the same imperial examination cohort）

## Mental Models
- **Use the 门房等级 frame when** an institution classifies you by physical location — read your gatehouse, your chair, your floor; the building is the org chart.
- **Use the 识别绰号 model when** entering an in-group — name both formal title and informal nickname to signal that you've been pre-introduced.
- **Use the 三链接验证 frame when** assessing a stranger's true network — ask: same year of examination? same teacher? same recommender? Triple links = trust; one link = probe; zero links = stranger.

## Anti-patterns
- 报家门时遗漏关键节点：王用汲若只说"我是王用汲"而不提谭纶，本次对话不会生成任何后续。
- 把门房分配当成失礼：被领进右门房不是侮辱，是编码；愤怒在编码之下读不出诚实。

## Worked Example
臬司衙门，书办把海瑞领进右边的门房——品级低的一间，两排长条凳。屋里先到的王用汲起身："幸会。在下王用汲，新任建德知县。"海瑞报名；王用汲立刻接"果然是刚峰兄，海笔架"，再自报"贱字润莲。谭纶谭子理和我是同科好友"。海瑞马上回问："润莲兄也是谭子理举荐的吧？"三句话，籍贯、字号、座主、同科全部交换完毕。

海瑞赶了五天路，天黑进城，还没吃饭，从怀里掏出干硬的荷叶米粑就啃；王用汲去提壶，壶是空的。同一间门房里，高翰文到了，因书办不给茶，解下腰间玉佩递过去，书办脸色立刻好转。

三个人尚未升堂，位置已经排好：海瑞在最冷的门房吃冷粑，王用汲以同科之谊递水，高翰文用玉佩买一壶茶。门房是组织图，绰号是入场券，而一块玉佩提前暴露了高翰文处理关系的方式。

## Key Takeaways
1. 新官到任的前 5 分钟是体制对你的第一次分类——看门、看板、看座。
2. 自报家门时同时携带字号与引荐人，是大明朝"快速 KYC"的标准格式。
3. 绰号是反向身份证——"海笔架"三个字把体貌、字号、声望打包。
4. 同科、同窗、同引荐人是信任三角，三点共线才会结盟。
5. 第一次对话的信息密度决定未来关系的形态；海瑞与王用汲用最少字完成最高密度建档。
6. 同一间门房里的三种待茶方式，比三份履历更早说明谁会做事、谁会做官。
7. 清廉不是姿态：吃冷粑、不支使书办，都是可观察的成本信号。
