# Chapter 2: 改稻为桑与踏苗 (Convert Rice to Mulberry & Trample the Seedlings)

## Core Idea
朝廷"改稻为桑"国策在浙江的推行变成了一场以马蹄碾压青苗、以木牌改写田籍的暴力仪式——政策与执行之间隔着一整条人命的距离，张居正等人的预言"一开始推行就给百姓带来灾难"在桃花汛过后精准兑现。

## Frameworks Introduced
- **堰口截流 / 上善若水的反讽**（The Inverted Benevolence）— 新安江水"上善若水"本应润田，却被两岸大堤截住"向下奔流"。用《道德经》箴言对照现实施政，构成"叙事-行为"反差分析。
- **踏苗—插牌两步执行术**（Trample-Then-Plant Protocol）— 先物理消灭既有作物（踏苗），再木牌钉入田心（插牌），两步完成"既成事实"。当物理行动比文书命令快，政策就被暴力落地。
- **国策—地方—百姓的三段断裂**（Three-Link Disconnect）— 国策（中央意图）→ 地方强制（行政扭曲）→ 百姓绝境（执行反噬）。每一段都有独立利益。

## Mental Models
- **Use the 踏苗—插牌 frame when** a destructive policy must become irreversible — first destroy the prior state, then mark it as new. Reversal cost > initial cost by design.
- **Use the 三段断裂 model when** central policy has unintended harm — map each link (intent / implementer / victim) to a separate interest, and you'll find no actor is responsible for the cumulative damage.
- **Use the 反讽叙事 frame when** an institution invokes lofty moral language ("上善若水") while performing the opposite — the gap itself is the indictment.

## Anti-patterns
- 以"国策"为挡箭牌施暴：把中央意图当作暴力执照，"反正我也是奉命"。
- 单点强制无配套：只下达命令不提供替代生计，百姓从生产滑向绝境。
- 把可逆问题当不可逆处理：种下的青苗本可保粮，先踏苗就把回退路径切断。

## Worked Example
四月，新安江大堤。马宁远一声"踏苗"，马队踏过青苗；常伯熙、张知良紧接着喊"插牌"，衙役把写着"桑田"的木牌钉进田心。一个老人扑在田里，张开双臂护苗；齐大柱喊"反正是死，拼了吧"，带着青壮列成人墙。奔马在离人墙不到一丈处被硬生生勒停。

马宁远没有后退，而是把"挡马"重新定义为"谋反"：他先问"刚才说'反了'的人是谁"，齐大柱答"是我"；再问姓名营生，然后突然问"你在王直那儿当什么头目？"——一句话把抗税农民变成倭寇同党。踏苗制造不可逆的事实，插牌完成产权改写，罪名预制则负责让反抗者失去申诉资格。三步走完，政策就不再是政策，而是一场已经开局的刑事案。

## Key Takeaways
1. 国策的真正考验不在颁布，而在第一个堰口是否被堵。
2. 当文书命令落后于物理行动（先踏苗再插牌），法律事实已被暴力改写。
3. "上善若水"等道德修辞与现实暴行并置时，修辞本身成为控告书。
4. 一项政策若在第一公里就让百姓跪满大堤，崩盘只是时间问题。
5. 任何政策都应先问：执行链中哪一段拥有否决权？哪一段承担代价？
6. 当反抗者被迅速改写成"反民""倭党"，说明执行者需要的不是服从，而是可以定罪的证据。
7. "青苗"是粮食，也是产权凭证；踏苗踏掉的是当年的收成，插牌插下的是未来的地权。
8. 政策的第一个受害者出现时，执行者若只加罪名、不改方案，崩盘已经开始。
