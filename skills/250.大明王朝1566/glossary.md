## 官职与机构

- **内阁**：票拟中枢，首辅、次辅与群辅；严嵩、徐阶先后掌权。
- **司礼监**：宦官最高机构，掌印太监统管，秉笔太监代皇帝批红。
- **票拟 / 批红**：内阁拟处理意见，司礼监以朱笔批准；批红是最终生效环节。
- **江南织造局**：为宫廷采办丝绸的机构，实为皇帝私库与白手套网络。
- **总督 / 巡抚 / 按察使 / 知府 / 知县**：地方军政、监察、行政层级；总督高于巡抚。
- **锦衣卫 / 提刑司 / 镇抚司 / 诏狱**：侦察、抓捕、审讯系统，可绕过常规司法。
- **卫所 / 军户**：军事要隘设卫，军户世袭，子承父籍，是明代常备兵源。
- **翰林院 / 都察院 / 国子监 / 通政使司**：清流与言官集中之地，清贫而敢于弹劾。

## 政策与事件

- **改稻为桑**：将浙江稻田改为桑田，以多产丝绸填补国库；执行中演变为强制毁田。
- **以改兼赈**：以改稻为桑兼作赈灾，让有粮大户买灾民田、灾民种桑；实为土地兼并。
- **毁堤淹田**：人为决堤淹没农田，逼灾民贱卖土地；严党与地方官合谋。
- **踏苗 / 插牌**：先踏毁青苗，再插"桑田"木牌，制造不可逆的既成事实。
- **奉旨赈灾**：沈一石把粮船挂上织造局灯笼与"奉旨赈灾"帖子，把买田包装成皇恩。
- **抄家**：查抄贪官/商人财产；沈一石案中成为筹军费与灭口的手段。
- **廷寄**：内阁发出的紧急指令，经司礼监批红后具有诏命效力。
- **廷杖**：在朝堂或院中杖打官员，既是惩罚，也是对所有言官的恐吓。
- **秋决 / 立决**：死刑分秋后处决与决不待时；海瑞被判秋决，立秋行刑。
- **罪己诏**：皇帝公开自责的诏书，用个人认错换取天命与合法性延续。
- **青词**：祭天用的骈文；严嵩、徐阶皆以青词得宠，人称"青词宰相"。
- **贺表**：庆典时百官必上的祝贺奏表；交不交、何时交，都是站队信号。
- **治安疏**：海瑞上嘉靖的著名奏疏，直指"视国为家、一人独治"。

## 关键术语

- **严党 / 清流**：以严嵩父子为核心的既得利益集团 vs. 以裕王师傅和言官为主的清议集团。
- **白手套**：替权力做脏活、可随时被否认的商人或机构，如沈一石与织造局。
- **干爹制**：用父子称谓包装庇护关系，拒绝任务等于不孝。
- **投鼠忌器**：查案要避开皇帝与宫里；"器"就是不可碰的权力核心。
- **官大无书生**：职位越高，越先算利害，越难坚持书生的是非。
- **同船共罪**：整个官僚系统都在一条船上，追责一人等于追责所有人。
- **年敬**：地方官每年向京官/权贵输送的礼金，是正式财政外的保护费。
- **盐引 / 盐税**：盐业专卖凭证与税收；盐政衙门被严党控制，成为私人提款机。
