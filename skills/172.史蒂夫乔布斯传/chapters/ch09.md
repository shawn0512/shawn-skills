# Chapter 9: 上市 — 名利双收

## Core Idea
IPO 把苹果从车库公司变成公众公司，也把乔布斯的人性放在聚光灯下：他对老友丹尼尔·科特基的冷漠、对沃兹慷慨的对比、以及精心管理的公众形象。财富放大了性格，而不是改变性格。

## Frameworks Introduced
1. **公众形象管理（Public Narrative Management）** — 乔布斯成为 IPO 的封面人物，选择投行、控制叙事。Use when 公司融资/上市：资本市场买的是故事与可信度，不只是财务。
2. **期权作为忠诚测试（Equity as Loyalty Test）** — 谁获得期权、谁被排除，暴露了权力结构与价值观。Use when 设计激励：分配规则比总额更能塑造文化。
3. **慷慨的复利（Generosity Compounding）** — 沃兹把期权低价卖给中层员工，赢得长期尊重；乔布斯对科特基的冷漠则留下永久裂痕。Use when 处理早期员工回报：短期省钱可能长期摧毁信任。
4. **法律前置（Legal Preemption）** — 上市前解决亲子鉴定与抚养协议，说明乔布斯懂得在关键节点处理风险。

## Key Concepts
- **1980年 IPO**：苹果估值 17.9 亿美元，300 人成为百万富翁。
- **丹尼尔·科特基**：早期挚友，因时薪身份未获期权，友谊破裂。
- **沃兹的期权赠与**：把个人收益分给被忽视的员工。
- **迈克·马库拉**：公司化与上市的关键推手。
- **公众乔布斯 vs 私人乔布斯**：形象与行为的割裂。

## Mental Models
- **Use 故事化 when 融资/上市**：把公司使命、增长逻辑、创始人可信度讲成一个连贯叙事。
- **Use 激励审计 when 分配股权**：问“谁被排除，为什么”，这比总额更能预测文化后果。
- **Use 慷慨 when 早期员工贡献难以精确计量**：适度超付，换取长期信任与口碑。
- **Use 法律前置 when 私人风险可能影响公司**：在关键交易前处理干净，避免被要挟。

## Anti-patterns
- 用“级别/工时”机械地排除早期贡献者，忽视隐性价值。
- 把忠诚当理所当然，直到对方崩溃才意识到关系已破裂。
- 只管理外部叙事，不管理内部公平。

## Worked Example
科特基守在乔布斯办公室外，想问清楚自己为什么没有期权。乔布斯让他“去跟经理谈”，从不正面解释。最终科特基冲进办公室，情绪崩溃，友谊终止。与此同时，沃兹把自己的期权低价卖给 40 名中层员工，很多人因此买得起房。两种处理方式，定义了两种领导者的长期声誉。

## Key Takeaways
1. 财富会放大既有性格，不会自动带来成熟。
2. 股权分配是价值观的公开声明。
3. 早期员工的隐性贡献，不能用工时简单衡量。
4. 公众形象可以管理，但内部公平无法长期伪装。
5. 在关键交易前处理私人风险，是负责任的做法。
