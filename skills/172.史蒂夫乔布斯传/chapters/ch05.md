# Chapter 5: Apple I — 开机，启动，接入……

## Core Idea
Apple I 的意义不在技术，而在“把极客玩具变成可购买的产品”。沃兹负责设计，乔布斯负责整机化、定价、渠道与叙事。个人电脑从俱乐部DIY走向大众市场，靠的是产品化能力，而不是更聪明的电路。

## Frameworks Introduced
1. **整机产品化（Appliance Productization）** — 用户不想买零件，他们想买“开箱即用”。Use when 技术产品仍停留在发烧友阶段：把电源、键盘、显示、软件整合成完整体验。
2. **渠道先行（Channel First）** — 先找到愿意进货的零售商（Byte Shop 的保罗·特雷尔），再用订单驱动生产。Use when 资源有限：用客户承诺降低库存与资金风险。
3. **叙事定价（Narrative Pricing）** — 同样的电路板，讲成“个人计算革命”的一部分，就能支撑更高价格与更强需求。
4. **合伙股权设计** — 乔布斯、沃兹、罗恩·韦恩的最初股权分配，以及韦恩很快退出，说明早期风险与角色认知的重要性。

## Key Concepts
- **家酿计算机俱乐部**：技术分享与反主流文化的交汇。
- **Byte Shop**：第一批订单来源，要求整机而非裸板。
- **Apple I**：沃兹的极简设计，乔布斯负责外壳、销售与交付。
- **罗恩·韦恩**：初始合伙人，因担心风险退出，错失巨额回报。
- **“开机，启动，接入”**：反文化口号，个人电脑作为解放工具。

## Mental Models
- **Use 整机化 when 技术受众太小**：把使用门槛降到“插电即可”，市场会大一个数量级。
- **Use 订单驱动 when 现金紧张**：先收承诺/预付款，再采购与生产。
- **Use 叙事 when 产品同质化**：功能相近时，意义与身份认同决定溢价。
- **Use 股权谈判 when 合伙创业**：把最坏情况（退出、稀释、分歧）提前写清。

## Anti-patterns
- 把“技术先进”当成“产品成立”；用户买的是结果，不是参数。
- 低估渠道与交付：没有零售与售后，再好的板子也到不了用户手里。
- 因恐惧风险而过早退出；风险判断要基于能力与信息，而非情绪。

## Worked Example
乔布斯拿着 Apple I 的裸板去 Byte Shop，保罗·特雷尔说：我可以要，但我要的是装好、能用的整机。乔布斯没有争辩技术细节，而是接下订单，回去组织生产、采购零件、安排交付。这个“先拿订单再组织资源”的动作，把车库项目变成了公司。

## Key Takeaways
1. 产品化的本质是降低用户的使用门槛。
2. 渠道不是附属，它决定了你能不能触达市场。
3. 现金流比技术完美更早决定创业生死。
4. 叙事能把技术价值翻译成大众可理解的意义。
5. 合伙人退出机制要在关系好时谈，而不是在危机时谈。
