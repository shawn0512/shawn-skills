# Chapter 7: 克里斯安和莉萨 — 被遗弃者……

## Core Idea
这是乔布斯人格中最黑暗的一条线：他否认亲生女儿莉萨，拒绝承担父亲责任，却又用“莉萨”命名电脑。被遗弃者成为遗弃者，创伤在没有被处理时会代际传递。产品天才与情感残废可以同时存在于一个人身上。

## Frameworks Introduced
1. **创伤循环（Trauma Loop）** — 被抛弃的人若未处理恐惧，会在亲密关系中重复抛弃行为。Use when 观察到一个成功者对家人/下属异常冷酷：不要只看道德，先看其恐惧结构。
2. **否认的代价（Denial Cost）** — 乔布斯长期否认亲子关系，直到 DNA 检测与公司上市压力迫使他就范。Use when 面对不愿处理的现实：拖延不会消除成本，只会把成本转移到关系与声誉。
3. **符号补偿（Symbolic Compensation）** — 用“莉萨”电脑命名来间接承认，却不肯直接面对女儿。Use when 组织用口号/命名替代真实行动：符号不能替代责任。

## Key Concepts
- **克里斯安·布伦南**：乔布斯高中女友，莉萨的母亲。
- **莉萨·布伦南-乔布斯**：1978年出生，最初不被承认。
- **DNA 检测**：94.41% 亲子概率，法院判令抚养费。
- **“莉萨”电脑**：官方解释为“本地集成系统架构”，实为女儿名字。
- **情感二元**：对产品极致投入，对亲人极度回避。

## Mental Models
- **Use 创伤循环 when 评估领导者**：他的冷酷可能不是策略，而是未被处理的恐惧；这会影响团队忠诚与家庭稳定。
- **Use 否认成本 when 拖延坏消息**：越晚面对，代价越大，且会伤害最亲近的人。
- **Use 符号补偿警报 when 组织用命名/口号代替行动**：问“真实资源与责任是否到位”。

## Anti-patterns
- 把天才的私德问题浪漫化；“他對产品好”不能抵消对家人的伤害。
- 用工作投入逃避家庭责任，并美其名曰“使命”。
- 让恐惧决定亲密关系，而不是让选择决定。

## Worked Example
莉萨出生后，乔布斯拒绝承认。克里斯安靠救济生活，最终诉诸法律。DNA 检测显示亲子概率 94.41%，法院判令每月 385 美元抚养费。与此同时，苹果的“莉萨”电脑以女儿命名，官方却编造了一个缩略词来掩盖。多年后乔布斯承认：“这很显然是以我女儿的名字命名的。”这个场景说明：他并非不知道，而是无法面对。

## Key Takeaways
1. 创伤会重复，除非被看见和处理。
2. 否认的成本会随时间指数级上升。
3. 产品命名、口号、公关不能替代真实责任。
4. 评价一个领导者要同时看创造价值与对待他人的方式。
5. 亲密关系中的勇气，与商业冒险中的勇气是两种不同的能力。
