# Chapter 17: 伊卡洛斯 — 凡升起的……

## Core Idea
Mac 发布后，乔布斯声望达到顶点，但销量不及预期、组织内耗、与斯卡利的权力斗争，最终导致 1985 年被董事会驱逐。这是“伊卡洛斯”式坠落：飞得太高、太自信，忽略了组织与市场的重力。

## Frameworks Introduced
1. **伊卡洛斯循环（Icarus Cycle）** — 成功→自信膨胀→忽视风险→权力冲突→坠落。Use when 个人/公司处于高光期：主动寻找逆耳信息，建立制衡。
2. **创始人被驱逐的结构（Founder Ouster Structure）** — 董事会、职业经理人、业绩压力三者结合，可以在创始人仍强势时将其移除。Use when 创始人VS董事会冲突：提前设计治理结构，避免零和。
3. **团队清洗的代价（Purge Cost）** — 乔布斯合并 Lisa/Mac 团队时公开羞辱“二流团队”，短期集中权力，长期制造恐惧与人才流失。Use when 组织合并：裁撤要透明、尊重，否则文化受损。
4. **A 级团队原则** — “一流队员只喜欢和一流队员合作，不能容忍二流队员。”Use when 团队扩张：招聘标准一旦下降，会连锁下降。

## Key Concepts
- **Mac 销量不及预期**：1984 年后销售放缓。
- **斯卡利与乔布斯的权力斗争**：从“灵魂伴侣”到董事会对立。
- **1985 年 5 月**：乔布斯被解除 Mac 部门职务。
- **1985 年 9 月**：乔布斯辞去苹果董事长，创立 NeXT。
- **“二流团队”讲话**：冷酷合并的典型案例。
- **A 级/B 级/C 级员工连锁反应**。

## Mental Models
- **Use 伊卡洛斯检查 when 处于巅峰**：问“如果核心假设错了，谁会告诉我”。
- **Use 治理设计 when 创始人强势**：董事会构成、投票权、继任机制要提前约定。
- **Use A级招聘 when 团队扩张**：宁可空缺，不要用 B 级填坑。
- **Use 合并尊重 when 裁撤团队**：公开羞辱会传染恐惧，影响留下的人。

## Anti-patterns
- 把成功归因于自己，把失败归因于他人。
- 用公开羞辱建立权威；短期有效，长期破坏信任。
- 创始人拒绝任何制衡，最终被制衡机制反噬。

## Worked Example
Lisa 与 Mac 团队合并时，乔布斯对 Lisa 团队说：“你们失败了，你们是二流团队。”他裁掉四分之一的人，把高层职位全部给 Mac 团队。阿特金森认为这不公平：Lisa 团队也很努力、很有才华。乔布斯则坚持“不能容忍二流队员”。几个月后，Mac 销量不佳，董事会站在斯卡利一边，乔布斯被驱逐。他用来对待别人的“二流”逻辑，最终也落到了自己身上。

## Key Takeaways
1. 巅峰期是最危险的时期，需要主动引入逆耳信息。
2. 创始人与职业经理人的冲突，往往是治理结构问题。
3. A 级团队原则有效，但不能成为羞辱他人的借口。
4. 公开羞辱会留下长期文化创伤。
5. 被驱逐不一定是终点；乔布斯用 NeXT/Pixar 重建了自己。
