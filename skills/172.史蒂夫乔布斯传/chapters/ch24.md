# Chapter 24: 复出 — 此刻的失败者终将胜利

## Core Idea
乔布斯回归后做的第一件事不是“加产品”，而是“做减法”：砍掉 70% 的产品线，把苹果从混乱的多产品公司变成“四个格子”的聚焦公司。复出的核心不是创意，而是优先级、组织清洗与执行纪律。

## Frameworks Introduced
1. **四格聚焦（Four-Quadrant Focus）** — 用“消费级/专业级 × 台式/便携”两个维度，只做四款产品。Use when 产品线膨胀：用两个关键维度切分，砍掉其余。
2. **减法领导（Leadership by Subtraction）** — 取消 Newton、克隆机、打印机等非核心项目。Use when 资源分散：每个项目都要证明它能成为“第一或第二”。
3. **“A 级团队”重组** — 换掉不认同产品优先的高管，引入库克等运营人才。Use when 文化需要转向：关键岗位必须由认同新优先级的人担任。
4. **聚焦的代价（Focus Trade-offs）** — 砍项目会伤害团队、媒体与用户，但不砍会拖死公司。Use when 转型：公开解释“为什么不做”，并给被影响的人体面。

## Key Concepts
- **1997 年回归**：先任顾问，后任 iCEO。
- **“四个格子”**：Power Mac G3、PowerBook G3、iMac、iBook。
- **砍掉 Newton**：PDA 项目被终止，团队被重新分配。
- **克隆机协议终止**：收回授权，保护体验与利润。
- **微软投资**：1997 年 1.5 亿美元，换取 Mac 版 Office 与和解。
- **“专注”**：乔布斯管理哲学的核心词。

## Mental Models
- **Use 四格 when 产品线混乱**：选两个对用户最重要的维度，只保留每格一款。
- **Use 减法 when 资源不足**：先决定“不做什么”，再谈“做什么”。
- **Use 关键岗位重置 when 文化转向**：不认同新优先级的高管必须离开，否则改革会被稀释。
- **Use 公开解释 when 砍项目**：说明战略逻辑，减少谣言与士气损失。

## Anti-patterns
- 用“多元化”掩盖缺乏焦点。
- 保留所有项目以取悦所有人，结果没有一个产品足够好。
- 砍项目时不尊重团队，制造恐惧文化。

## Worked Example
乔布斯回归后，苹果有几十条产品线，包括打印机、Newton、克隆机。他画了一个 2×2 的格子：消费级/专业级、台式/便携。然后宣布只做四款产品。Newton 被砍，团队被重新分配；克隆机授权被终止。很多人愤怒，但苹果的资源终于集中。配合 iMac 的推出，苹果在 1998 年重新盈利。这个案例说明：复出不是“更努力”，而是“更少但更对”。

## Key Takeaways
1. 危机中的第一动作通常是减法，而不是加法。
2. 聚焦需要明确的维度与残酷的取舍。
3. 关键岗位必须与战略一致，否则改革会被内部抵消。
4. 砍项目要解释逻辑、尊重团队。
5. 专注不是口号，是资源分配的硬约束。
