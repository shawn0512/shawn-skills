# Chapter 37: 第二回合 — 癌症复发

## Core Idea
2008 年癌症复发，乔布斯在健康、工作与公众形象之间反复拉扯：他隐瞒病情、推迟手术、接受肝移植，同时继续主导 iPhone/iPad。这一章展示“控制欲”在身体面前的极限，以及领导者的健康如何成为公司治理问题。

## Frameworks Introduced
1. **健康治理（Health Governance）** — CEO 健康直接影响公司估值与继任计划，不能只当私事。Use when 关键人物健康风险：董事会应有披露与继任机制。
2. **控制幻觉（Illusion of Control）** — 乔布斯试图控制病情信息、饮食、工作时间，但无法控制疾病。Use when 面对不可控风险：区分“可行动部分”与“必须接受部分”。
3. **工作作为意义（Work as Meaning）** — 病中仍坚持产品发布，工作是他对抗死亡的方式。Use when 面对存在性危机：找到能提供意义的活动，但不要用它否认现实。
4. **继任前置（Succession Before Crisis）** — 乔布斯最终推动库克接任，但过程不透明。Use when 创始人不可替代：尽早建立继任与过渡机制。

## Key Concepts
- **2008 年复发**：癌细胞扩散。
- **2009 年肝移植**：在孟菲斯进行。
- **体重骤减**：进食困难、疼痛、心理因素。
- **保密文化**：苹果对 CEO 健康信息高度控制。
- **继续工作**：病中仍参与 iPhone/iPad 决策。
- **继任问题**：库克逐步接管日常运营。

## Mental Models
- **Use 健康治理 when 关键人物患病**：把健康风险纳入公司治理，而不是只靠个人意志。
- **Use 可控/不可控 when 面对疾病**：把精力放在治疗、作息、支持系统，而不是否认诊断。
- **Use 意义活动 when 存在性危机**：工作可以提供意义，但不能替代治疗与家庭。
- **Use 继任前置 when 创始人不可替代**：提前培养、授权、披露，减少震荡。

## Anti-patterns
- 隐瞒关键健康信息，导致市场与团队被动。
- 用工作麻痹自己，忽视身体信号。
- 把“坚持工作”浪漫化，忽略家人与同事的负担。

## Worked Example
2008 年，乔布斯体重骤减 40 磅，公众开始猜测。苹果先称“荷尔蒙失调”，后承认健康问题。2009 年他接受肝移植，期间库克负责日常运营。乔布斯在病中仍参与 iPad/iPhone 决策，但是否披露、何时披露、如何继任，始终缺乏透明机制。这个案例说明：创始人的健康不是私事，它关系到员工、股东与产品的连续性。

## Key Takeaways
1. 关键人物健康是治理问题，不只是隐私问题。
2. 控制欲在疾病面前有边界。
3. 工作可以提供意义，但不能替代治疗。
4. 继任计划要在危机前建立。
5. 透明与信任，比“完美形象”更可持续。
