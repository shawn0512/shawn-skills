# Chapter 13: 制造Mac — 过程就是奖励

## Core Idea
Mac 的制造过程展示了乔布斯式执行：用使命压过资源限制，用内部竞争制造紧迫感，用“过程就是奖励”让团队把工作本身当成回报。但同一套方法也带来内耗、透支与对失败者的残酷。

## Frameworks Introduced
1. **过程即奖励（The Journey Is the Reward）** — 把卓越工作本身视为回报，而不只盯着上市/奖金。Use when 项目周期长、不确定性高：用工艺自豪感维持士气。
2. **良性竞争→恶性竞争的分界线** — 乔布斯用 Mac vs Lisa 的内部竞争激励团队，但竞争升级为互相拆台。Use when 设计团队竞争：竞争对象应是问题/外部对手，不是同事。
3. **资源重定向（Resource Reallocation）** — 把最好的工程师从 Apple II 抽到 Mac，甚至直接拔电源。Use when 旧产品仍赚钱但未来在别处：敢于把资源从“现在”移到“下一步”。
4. **高标准 + 直接反馈** — 乔布斯当面斥责“狗屎”，也当面称赞“完美”。Use when 团队习惯平庸：反馈要具体、及时，但避免人身攻击。

## Key Concepts
- **Mac 团队**：赫茨菲尔德、伯勒尔·史密斯、阿特金森、科尔曼等。
- **与 Lisa 的竞争**：赌 5000 美元、抢工程师、争资源。
- **IBM PC 的威胁**：1981 年发布，苹果一度低估。
- **“过程就是奖励”**：乔布斯常引用的信条。
- **现实扭曲力场**：激进工期与“必须做到”的文化。

## Mental Models
- **Use 过程奖励 when 项目漫长**：强调工艺、团队身份、对用户的影响，而非只谈期权。
- **Use 资源重定向 when 新旧业务冲突**：明确未来主线，把最强的人放上去。
- **Use 竞争设计 when 需要紧迫感**：让团队与外部标准/难题竞争，避免同事互害。
- **Use 直接反馈 when 质量问题反复出现**：对事不对人，给出可执行的修改标准。

## Anti-patterns
- 把内部竞争变成政治斗争，导致信息隐藏与重复劳动。
- 用“过程就是奖励”美化无偿加班与 burnout。
- 只批评不解释，团队不知道“好”的标准是什么。

## Worked Example
乔布斯走进赫茨菲尔德的工位，问他为什么还在做 Apple II 的 DOS 程序。赫茨菲尔德解释手头工作的重要性。乔布斯说：“谁在乎 Apple II？用不了几年它就会消亡。Mac 才是未来。”然后拔掉电源，毁了未保存的代码，开车把他和电脑一起拉到 Mac 办公室。这个极端场景说明：资源重定向需要果断，但方式可以更尊重人；乔布斯选择了最具冲击力、也最伤人的做法。

## Key Takeaways
1. 资源必须跟着未来走，而不是跟着现有收入走。
2. 内部竞争要有边界，否则会摧毁协作。
3. 高标准需要清晰标准与具体反馈，否则只是暴君式挑刺。
4. “过程即奖励”能激励人，也可能被用来掩盖剥削。
5. 执行力的核心是优先级，而不是让所有人同时做所有事。
