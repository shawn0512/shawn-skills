# Chapter 20: 凡人 — 爱就那么回事

## Core Idea
乔布斯在亲密关系中反复上演“靠近—伤害—离开”的模式：与琼·贝兹、黛安·基顿、蒂娜·莱德斯的关系都证明，他能理解产品的细节，却难以理解人的情感。天才的感知力并不自动转化为共情能力。

## Frameworks Introduced
1. **亲密关系中的二元模式（Intimacy Binary）** — 极度浪漫 + 极度回避，源于对脆弱的恐惧。Use when 观察高成就者的私人关系：不要用事业成功推断情感成熟。
2. **投射式爱情（Projection Love）** — 乔布斯爱的是对方身上的符号（贝兹与迪伦的关联），而非完整的人。Use when 选择伴侣：区分“他代表什么”和“他是谁”。
3. **工作作为逃避（Work as Avoidance）** — 用使命、产品、会议填满时间，避免面对关系中的冲突。Use when 自己/他人长期用忙碌回避亲密：把关系质量纳入复盘。
4. **情感学习曲线** — 直到遇到劳伦并建立家庭，乔布斯才部分学会承担。Use when 评估成长：看长期行为变化，而不是一次道歉。

## Key Concepts
- **琼·贝兹**：民谣歌手，曾与鲍勃·迪伦相恋；乔布斯被这种关联吸引。
- **黛安·基顿**：演员，短暂恋情。
- **蒂娜·莱德斯**：长期女友，聪明独立，最终分开。
- **“爱就那么回事”**：贝兹的歌，也是乔布斯情感态度的隐喻。
- **红裙子故事**：他赞美却不买，显示“浪漫的表达”与“实际的付出”脱节。
- **害怕浪漫**：既渴望又逃避。

## Mental Models
- **Use 投射检查 when 被某人强烈吸引**：问“我爱的是他，还是他身上的某个符号/故事”。
- **Use 行为证据 when 判断情感成熟**：看长期行动（在场、承担、修复），而不是语言与礼物。
- **Use 忙碌警报 when 关系持续恶化**：工作成就是否被用来合理化缺席。
- **Use 成长视角 when 评价一个人**：允许改变，但要求看到持续行为差异。

## Anti-patterns
- 把“不懂表达”浪漫化，忽视对方的实际感受。
- 用礼物/赞美替代承诺与在场。
- 选择“符号型伴侣”来补全自我叙事，而非选择真实的人。

## Worked Example
乔布斯带琼·贝兹去拉尔夫·劳伦店，整晚称赞一条红裙子适合她。贝兹以为他要买给她，结果他给自己买了一堆衬衫，然后离开。贝兹后来困惑地说：“他会送我电脑，却不送我裙子。”这个场景说明：他能用产品表达关心，却害怕用亲密关系中的常规行动表达爱；浪漫的言辞与实际的付出之间，有一道他跨不过去的沟。

## Key Takeaways
1. 事业成就不等于情感成熟。
2. 投射式爱情会让人爱上“符号”，而不是真实的人。
3. 忙碌可以成为逃避亲密的完美借口。
4. 判断爱意要看长期行为，而不是高光时刻。
5. 成长是可能的，但需要持续的关系实践。
