# Chapter 14: 斯卡利来了 — 百事挑战

## Core Idea
乔布斯用一句“你是想卖一辈子糖水，还是想跟我一起改变世界”把约翰·斯卡利从百事挖到苹果。这是一次经典的愿景招募，也是一次严重的角色错配：斯卡利擅长营销与大公司管理，却不理解产品与技术；乔布斯需要导师，却无法接受被管理。

## Frameworks Introduced
1. **愿景招募（Vision Recruiting）** — 用“改变世界”的使命打动候选人，而不是只谈薪酬与头衔。Use when 招募顶级人才：先回答“这件事为什么值得他用生命的一部分来做”。
2. **角色匹配审计（Role Fit Audit）** — 斯卡利是营销强、产品弱、大公司型；苹果需要的是能管住创始人的运营者。Use when 高管招聘：列出岗位真正需要的 3 项能力，再对照候选人，而不是被名气吸引。
3. **创始人-职业经理人张力** — 创始人要控制产品，经理人要建立流程；两者需要明确权责边界。Use when 引入职业 CEO：提前约定决策权、董事会结构、冲突解决机制。
4. **百事挑战式营销** — 用可感知的对比实验证明优势。Use when 产品优势难以用参数表达：设计一个用户能亲身体验的对比场景。

## Key Concepts
- **约翰·斯卡利**：百事可乐总裁，“百事挑战”营销的操盘手。
- **“卖糖水 vs 改变世界”**：招募话术的经典。
- **唐·埃斯特里奇**：IBM PC 负责人，拒绝乔布斯邀请。
- **角色错配**：营销专家 vs 产品公司 CEO。
- **董事会结构**：为后来的权力斗争埋下伏笔。

## Mental Models
- **Use 愿景招募 when 候选人已有高薪高位**：给他一个“更大的自己”，而不是更好的合同。
- **Use 角色匹配 when 招聘高管**：区分“过去成功的原因”和“新岗位需要的能力”。
- **Use 权责边界 when 创始人引入CEO**：写清谁对产品、预算、人事有最终决定权。
- **Use 对比营销 when 优势可体验**：让用户自己得出结论，比广告宣称更有力。

## Anti-patterns
- 被名气和话术打动，忽视岗位真正需要的能力。
- 创始人既想要导师，又拒绝被指导；这会让职业经理人无法履职。
- 用愿景招募却不给匹配的权责，候选人很快会失望。

## Worked Example
乔布斯飞到纽约见斯卡利，在中央公园散步时问：“你是想卖一辈子糖水，还是想跟我一起改变世界？”斯卡利被击中，最终加入苹果。但入职后，乔布斯拒绝被管理，斯卡利又缺乏产品判断，两人从“灵魂伴侣”走向权力斗争。招募成功不等于匹配成功；这句话打开了门，却没解决门后的结构问题。

## Key Takeaways
1. 愿景是招募顶级人才的入场券，但不是留人的充分条件。
2. 高管招聘要区分“名气”与“岗位能力”。
3. 创始人引入 CEO 前，必须谈清权责与退出机制。
4. 营销天才不一定能管产品公司；能力有场景。
5. 关系初期的高浓度赞美，可能掩盖结构性冲突。
