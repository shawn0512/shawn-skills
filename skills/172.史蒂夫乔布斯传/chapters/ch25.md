# Chapter 25: 非同凡想 — iCEO乔布斯

## Core Idea
“Think Different”不是产品广告，而是品牌灵魂的重建：苹果不只卖电脑，它代表“挑战现状的创造性精神”。乔布斯用这则广告先对内部员工说话，再对外部世界说话——先让苹果人想起自己是谁，再让用户重新认识苹果。

## Frameworks Introduced
1. **品牌即身份（Brand as Identity）** — 不卖功能，卖“你是谁/你属于谁”。Use when 产品同质化：用价值观与身份建立情感连接。
2. **对内先行（Inside-Out Branding）** — 先让员工重新相信，再让外部感知。Use when 品牌老化：内部认同是外部传播的前提。
3. **“致疯狂的人”叙事（Crazy Ones Narrative）** — 把历史上的反叛者/创造者作为品牌代言人，不出现产品。Use when 需要重建意义：用文化符号而非参数。
4. **聚焦 + 品牌双轮** — 产品做减法，品牌做意义加法；两者同时进行。Use when 公司转型：一边收缩产品线，一边重建叙事。

## Key Concepts
- **李·克劳**：TBWA\Chiat\Day 创意总监，“1984”与“Think Different”的创作者。
- **“致疯狂的人”**：广告文案，赞美改变世界的反叛者。
- **iCEO**：临时 CEO 的头衔，乔布斯用它降低预期、保留退出选项。
- **微软投资**：1997 年，1.5 亿美元 + Office for Mac。
- **品牌重建**：从“卖电脑”到“创造性工具”。

## Mental Models
- **Use 身份品牌 when 功能差异小**：问“用户希望通过使用我们，成为什么样的人”。
- **Use 对内先行 when 品牌老化**：先让员工相信，再投放广告。
- **Use 文化符号 when 讲故事**：用人物、时刻、价值观，而不是规格表。
- **Use 临时头衔 when 权力未稳**：iCEO 既降低外界预期，也保留谈判空间。

## Anti-patterns
- 品牌口号与产品体验不一致；用户会感到被欺骗。
- 只对外宣传，内部员工不相信。
- 用“伟大”这个词自我标榜，却没有具体行动证明。

## Worked Example
乔布斯回归后，苹果需要重新定义自己。李·克劳带来“Think Different”创意：黑白影像中的爱因斯坦、甘地、马丁·路德·金、毕加索等“疯狂的人”，旁白说“他们推动人类向前”。广告没有展示一台电脑。乔布斯看后流泪，因为他知道这正是苹果的灵魂。随后，苹果把“不同凡想”落到 iMac 等产品上：品牌承诺必须有产品兑现。

## Key Takeaways
1. 品牌的核心是身份，不是功能列表。
2. 内部认同先于外部传播。
3. 文化符号比参数更能建立情感连接。
4. 品牌承诺必须由产品体验兑现。
5. 临时头衔可以降低预期，但不能替代实际权力。
