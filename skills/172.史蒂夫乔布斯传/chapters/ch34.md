# Chapter 34: 21世纪的Mac — 苹果脱颖而出

## Core Idea
这一章是“设计驱动”的辩证课：G4 Cube 证明“设计过度 + 定价过高”会失败；向日葵 iMac 证明“形式表达功能”会成功。乔布斯并非永远正确，但他能从失败中提炼出“设计必须服务价格与使用场景”的教训。

## Frameworks Introduced
1. **设计过度陷阱（Overdesign Trap）** — G4 Cube 追求纯粹美学，忽视价格与主流需求，销量惨败。Use when 设计获得赞美但销量不佳：检查价格、场景、可扩展性。
2. **形式表达功能（Form Expresses Function）** — 向日葵 iMac 的屏幕与底座分离，像向日葵追光，表达纯平显示器的灵活性。Use when 设计需要隐喻：让形状来自功能，而不是装饰。
3. **设计分层（Design Tiering）** — 专业级与消费级需要不同的设计/价格策略。Use when 产品线分层：不要用同一套美学覆盖所有市场。
4. **失败后校准（Post-Failure Calibration）** — Cube 失败后，乔布斯在 iPod 上控制成本、按时发布。Use when 项目失败：提取约束，应用到下一个产品。

## Key Concepts
- **Power Mac G4 Cube**：8 英寸立方体，进入 MoMA，但销量失败。
- **设计过度**：美学优先，价格/扩展性失衡。
- **向日葵 iMac**：屏幕与底座分离，隐喻追光。
- **纯平显示器转型**：从 CRT 到 LCD。
- **成本/价格平衡**：iPod 的成功因素之一。
- **“简化去除多余”**：乔布斯的 design credo。

## Mental Models
- **Use 过度设计检查 when 设计获赞但卖不动**：问“目标用户是否愿意为美学付溢价”。
- **Use 功能隐喻 when 设计形状**：让形态来自使用方式，而不是装饰冲动。
- **Use 分层 when 多市场价格带**：专业用户与大众用户的支付意愿不同。
- **Use 失败校准 when 项目失败**：把教训写成下一款产品的硬约束。

## Anti-patterns
- 把“进入博物馆”当成商业成功。
- 用同一套高端设计覆盖大众市场。
- 失败后只怪市场，不检查定价与场景。

## Worked Example
G4 Cube：无风扇、无按钮、完美立方体，被视为设计杰作，进入 MoMA。但普通专业人士不需要桌上的雕塑，大众消费者不愿付两倍价钱。首个季度只卖出预期一半，第二季度低于 3 万台。乔布斯后来承认“设计过度且定价过高”。随后，他在 iPod 上控制成本、按时发布，取得巨大成功。这个对比说明：设计必须与价格、场景、规模匹配。

## Key Takeaways
1. 设计赞美不等于商业成功。
2. 形式应表达功能，而不是炫技。
3. 不同市场层级需要不同设计策略。
4. 失败要转化为下一款产品的约束。
5. 成本控制是设计的一部分，不是敌人。
