# Chapter 27: iMac — “你好（又见面了）”

## Core Idea
iMac 是乔布斯回归后的第一款大众产品，也是“设计驱动复兴”的证明：一体化、半透明、邦迪蓝、无软驱、提手。它把电脑从米色盒子变成有情感的家电，让苹果重新变得“酷”，并用销量证明设计可以转化为商业结果。

## Frameworks Introduced
1. **情感化硬件（Emotional Hardware）** — 半透明外壳、颜色、提手，让用户想触摸、想展示。Use when 产品是日用品：设计要创造“想拥有”的冲动，而不只是“能用”。
2. **删除过时标准（Delete Legacy Standards）** — 取消软驱，押注网络与 USB。Use when 旧标准仍普遍但已过时：算清用户真实使用场景，敢于领先一步。
3. **一体化消费电子（All-in-One Consumer Electronics）** — 屏幕、主机、键盘整合，开箱即用。Use when 家庭用户：降低安装与维护复杂度。
4. **发布剧场（Launch Theater）** — “你好（又见面了）”呼应 1984 年 Mac，制造传承感。Use when 品牌需要重启：用历史符号连接过去与未来。

## Key Concepts
- **iMac**：1998 年 5 月发布，1299 美元。
- **邦迪蓝**：半透明海蓝色外壳，灵感来自邦迪海滩。
- **无软驱**：大胆删除，推动 USB 与网络传输。
- **提手**：情感与功能结合，让电脑显得可接近。
- **“你好（又见面了）”**：发布会口号，呼应初代 Mac。
- **销售成绩**：6 周 27.8 万台，年底 80 万台。

## Mental Models
- **Use 情感化 when 产品同质化**：让用户想摸、想放客厅、想给别人看。
- **Use 删除旧标准 when 技术拐点**：问“用户上次用软驱是什么时候”，而不是“别人都还有”。
- **Use 一体化 when 目标用户怕麻烦**：减少线缆、安装、兼容性问题。
- **Use 历史符号 when 品牌重启**：用一句口号/一个设计元素连接品牌记忆。

## Anti-patterns
- 为差异化而差异化，颜色/形状不服务体验。
- 过早删除用户仍依赖的标准，造成实际不便。
- 设计过度导致成本/价格失控（参见 G4 Cube）。

## Worked Example
iMac 发布前，工程部门反对提手、反对取消软驱、反对半透明外壳。乔布斯坚持：“因为我是 CEO，我认为这么做没问题。”发布会现场，他用“你好（又见面了）”唤醒 1984 年 Mac 的记忆。iMac 成为苹果史上销售最快的电脑，32% 的购买者是首次购机。这个案例说明：设计驱动的复兴需要领导者承担风险，并用销量证明判断。

## Key Takeaways
1. 设计可以成为大众市场的增长引擎。
2. 删除过时标准需要勇气，也需要对用户场景的判断。
3. 情感化设计能创造“想拥有”的冲动。
4. 品牌重启可以用历史符号建立传承。
5. 领导者的坚持必须接受市场验证。
