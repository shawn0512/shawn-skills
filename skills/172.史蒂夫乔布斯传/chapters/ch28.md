# Chapter 28: CEO — 多年之后，疯狂依旧

## Core Idea
乔布斯从“产品天才”成长为“运营 CEO”：他学会外包制造、压缩库存、建立供应链、引入蒂姆·库克，并用极端的问责制执行。疯狂没有消失，但被装进了纪律的框架。苹果的复兴不仅靠设计，也靠运营。

## Frameworks Introduced
1. **专注 + 外包（Focus + Outsource）** — 砍产品线，把制造外包，自己控制设计、软件与品牌。Use when 垂直整合成本过高：保留高价值环节，外包低差异化环节。
2. **库存即负债（Inventory as Liability）** — 把库存期从两个月压缩到一个月，降低贬值风险。Use when 产品更新快：用准时制、供应商管理降低库存。
3. **极端问责（Extreme Accountability）** — 对供应商/高管设定硬指标，达不到就换。Use when 组织习惯妥协：用清晰后果建立执行文化。
4. **互补 COO（Complementary COO）** — 乔布斯负责产品/战略，库克负责运营/供应链。Use when 创始人强于产品弱于运营：找一位能补短板的二号位。

## Key Concepts
- **蒂姆·库克**：1998 年加入，供应链与运营专家，后接任 CEO。
- **库存期**：从超过两个月降到一个月。
- **制造外包**：关闭自有工厂，交给专业代工。
- **供应商管理**：硬谈判、准时交付、成本控制。
- **“专注”**：乔布斯管理哲学的核心。
- **问责文化**：不能容忍“差不多”。

## Mental Models
- **Use 保留高价值 when 外包**：设计、软件、品牌、零售体验自己控制；制造等低差异化环节外包。
- **Use 库存压缩 when 产品贬值快**：库存不是资产，是风险。
- **Use 硬指标 when 执行疲软**：每个关键环节都要有可验证的交付标准与后果。
- **Use 互补二号位 when 创始人偏科**：找能补运营/财务/供应链的人，而不是另一个自己。

## Anti-patterns
- 把“疯狂”当管理风格，忽视流程与数据。
- 对外包质量失控，损害品牌。
- 极端问责变成人身攻击，摧毁团队心理安全。

## Worked Example
乔布斯回归时，苹果库存期超过两个月，潜在损失高达 5 亿美元。他引入库克，关闭自有工厂，外包制造，硬性压缩库存到一个月；对供应商设定严苛交付标准，甚至因零件延迟大骂对方。结果，苹果的运营效率大幅提升，为 iMac、iPod 的爆发提供现金流与产能基础。这个案例说明：产品天才也需要运营纪律才能规模化。

## Key Takeaways
1. 设计驱动需要运营支撑，否则无法规模化。
2. 库存是风险，不是资产。
3. 外包不等于放弃控制；要控制标准与体验。
4. 创始人应找能补短板的二号位。
5. 问责要针对标准与结果，而不是人格羞辱。
