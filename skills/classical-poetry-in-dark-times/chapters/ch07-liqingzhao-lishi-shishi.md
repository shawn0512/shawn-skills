# Chapter 7: 李清照——离失的史诗

## Core Idea
李清照的生命故事以"离失"为核心：她在开头拥有一切，然后在国破、家亡、收藏散尽中一件件失去；她把丧失写成"聚—存—散—忆"的史诗，并以冒犯性的书写保存一个时代最后的春天。

## Frameworks Introduced
- **聚—存—散—忆 / 成住坏空**
  - When to use: 读《金石录后序》及一切收藏、丧失叙事。
  - How: 按时间顺序标出四阶段：聚（新婚购碑、赌书泼茶）、存（校勘题跋、编目）、散（三次遗失与掠夺）、忆（写后序）。四阶段对应万物生灭，收藏史即生命史。
- **残忍的减法**
  - When to use: 读逃难中的取舍段落。
  - How: 逐次列出"先去掉什么、又去掉什么"；每一次舍弃都不是最后一次，活下去意味着一次次降低底线。减法是伦理剧，不只是物资清单。
- **冒犯与解放**
  - When to use: 读《乌江》《金石录后序》《投翰林学士綦崇礼启》。
  - How: 找出文本冒犯了谁（赵明诚、南渡君臣、士大夫舆论、性别规范）；冒犯带来的解放，是李清照硬朗风格的来源。
- **追忆文学的壮丽**
  - When to use: 读《永遇乐·落日镕金》及易代追忆文本。
  - How: 看追忆如何把具体前朝事物提升为整个宇宙的完满；对宇宙的壮丽夸饰，即是对世界的告别准备。
- **诗歌是语言的琥珀**
  - When to use: 判断诗与史的关系。
  - How: 诗不是历史的注脚，而是"当事人的心灵、眼光与当日自然、社会的独特遇合"；它保存的是整体体验，不是事件清单。

## Key Concepts
- **《金石录》**：赵明诚、李清照合著的金石学巨著，著录两千种金石拓本。
- **金石学**：欧阳修开创，研究钟鼎碑刻；宋代五大家包括欧阳修、刘敞、赵明诚、洪适、王厚之。
- **南渡/靖康之变**：北宋灭亡、宋室南迁，收藏流散的历史背景。
- **三次遗失**：青州十余屋毁于战火；洪州近两万册书与两千卷拓本陷落；随身藏品被太医、军官、村民、张汝舟掠夺。
- **再嫁张汝舟**：晚年约百日婚姻，因不堪殴辱讼官，牵连入狱九日。
- **《投翰林学士綦崇礼启》**：骈体求告信，"猥以桑榆之晚景，配兹驵侩之下材"。
- **桑榆/驵侩**：暮年自指与牲口贩子，优雅与粗俗的陌生化对句。
- **成住坏空**：佛教四劫，对应收藏的聚存散忆。
- **中州盛日**：汴京元宵的盛世记忆。
- **元宵**：《永遇乐》的时间节点，也是新旧时代交替的象征。

## Mental Models
- Use "聚—存—散—忆" when 读任何物史、家族史、收藏史：把物的命运当人的命运。
- Use "残忍的减法" when 分析逃难/破产叙事：看每一次"还可以放弃什么"。
- Use "冒犯与解放" when 读女性写作：问她的硬朗从冒犯了什么禁忌而来。
- Use "诗歌是琥珀" when 诗与史冲突：优先保存心灵体验的真实。

## Anti-patterns
- **把李清照只读成婉约词人/"寻寻觅觅"**：会漏掉金石学家、批评者、冒犯者的面向。
- **忽略她的学术身份**：她不是赵明诚的附属，而是《金石录》的第二作者。
- **用道德评判再嫁**：会错过《投綦崇礼启》的雄辩与求生力量。
- **把《金石录后序》当普通回忆录**：它的结构、减法与冒犯都是精心设计的。

## Worked Example
《金石录后序》的减法段："既长物不能尽载，乃先去书之重大印本者，又去画之多幅者，又去古器之无款识者。后又去书之监本者，画之平常者，器之重大者……"读法：第一，注意舍弃顺序——先舍重、多、无款识，再舍监本、平常、重大，标准越来越低。第二，注意每一次都以为"这就是最后的舍弃"，但下一次还会来。第三，把这段与开头"质衣取半千钱，步入相国寺，市碑文果实归"对照：当年一件件买回，如今一件件丢下。收藏的聚与散构成完整闭环，这就是"离失的史诗"。

## Key Takeaways
1. 李清照的核心经验是"拥有—失去—追忆"。
2. 《金石录后序》以物的聚散写生命的成住坏空。
3. "残忍的减法"揭示乱世生存的伦理代价。
4. 她的硬朗来自冒犯：冒犯丈夫、君臣、士论与性别规范。
5. 追忆文学的壮丽，是对一个时代最后的告别。
