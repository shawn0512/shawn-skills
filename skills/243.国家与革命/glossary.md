# 术语表 — 国家与革命

**资产阶级法权** — 形式上平等、事实上不平等的权利关系。在社会主义阶段按劳分配中仍然存在。（Ch 5）

**巴黎公社** — 1871年法国工人建立的无产阶级政权，是无产阶级专政的第一次尝试。（Ch 3）

**暴力革命** — 被压迫阶级通过武装斗争推翻统治阶级、打碎旧国家机器的革命方式。（Ch 1）

**打碎国家机器** — 无产阶级革命的任务不是简单掌握旧的资产阶级国家机器，而是彻底摧毁它。（Ch 2）

**第二国际** — 1889-1914年的国际社会主义组织，因机会主义泛滥而在第一次世界大战中破产。（Ch 6）

**共产主义高级阶段** — 实现"各尽所能，按需分配"的社会形态，国家完全消亡。（Ch 5）

**共产主义第一阶段** — 刚从资本主义社会产生的社会主义社会，实行按劳分配，仍需国家。（Ch 5）

**国家消亡** — 随着阶级消灭，国家作为阶级压迫工具的功能自然消失。（Ch 5）

**国家实质** — 阶级统治的机关，一个阶级压迫另一个阶级的机关，阶级矛盾不可调和的产物。（Ch 1）

**机会主义** — 工人运动中对资产阶级妥协投降的倾向，放弃革命原则。（Ch 6）

**考茨基主义** — 考茨基的立场：形式上承认马克思主义，但"忘记"暴力革命和打碎国家机器。（Ch 6）

**居民的自动武装组织** — 与常备军对立的全民武装形式，公社的基本原则之一。（Ch 1）

**社会沙文主义** — 口头上的社会主义，实际上的沙文主义，在帝国主义战争中支持本国资产阶级。（Ch 1）

**无产阶级专政** — 从资本主义到共产主义过渡时期的国家形式，以工人阶级政治统治为基础。（Ch 3）

**按劳分配** — 社会主义阶段的分配原则：等量劳动领取等量产品，仍保留资产阶级法权。（Ch 5）

**按需分配** — 共产主义高级阶段的分配原则：各尽所能，按需分配。（Ch 5）

**特殊武装队伍** — 常备军和警察，国家政权的主要强力工具，与居民的自动武装组织对立。（Ch 1）

**阶级调和论** — 把国家说成调和阶级的机关的错误观点，是资产阶级和小资产阶级的理论。（Ch 1）

**阶级矛盾不可调和** — 国家产生的根本前提，国家存在即证明阶级矛盾不可调和。（Ch 1）
