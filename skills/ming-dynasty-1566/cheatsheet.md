# 速查表（Cheatsheet）

## 决策规则

1. **上司给你超规格恩宠** → 先问：这份恩情将来要用什么还？
2. **要动一个官员** → 先画举荐链、考功链、婚姻链；背景不清不动手。
3. **政策宣称"两全"** → 查谁出钱、谁得资产、谁承担剩余风险。
4. **汇报完美得不正常** → 脱掉身份去现场，先看全局再看细节。
5. **多份记录互相矛盾** → 并置，不逐份解释；矛盾本身就是证据。
6. **暴力推进快于程序** → 要案卷、管辖令、亲笔指令、时辰；用慢对抗快。
7. **收到无法回赠的礼** → 视为预付款，不是赏识。
8. **关键证人突然疯了/死了** → 先问谁从这份沉默中获益。
9. **组织说"他不是我们的人"** → 切割已开始，下一步是取证与清算。
10. **新朝释放旧臣** → 既是平反，也是收编；孤臣进入权力中心就不再是孤臣。
11. **下属说"没办法"** → 把困难换算成日期和后果，逼出具体动作。
12. **所有人都在表态** → 看谁没表态；缺席往往比发言更响。

## 识人信号（Tells）

| 信号 | 含义 |
|---|---|
| 赐座 / 撤座 | 圣眷的晴雨表；身体距离先于诏书 |
| 门庭若市 / 门可罗雀 | 权力正在流入或流出 |
| 礼物规格 | 未来任务的预付款额度 |
| 谁被允许进内院 | 内圈名单；门禁即站队 |
| 谁被点名 | 打击或测试；未被点名者会恐惧 |
| 谁先被传唤 | 权力排序与亲疏 |
| 谁抬轿、谁陪走 | 公开信号，给百官看的 |
| 家眷是否公开出现 | 政治身份是否仍被承认 |
| 上司突然示弱 | 多半是试探，不是信任 |
| 上司夸你"厚道" | 接下来要你让利 |

## 气味与陷阱（Smells）

- **"都是下面的人糟蹋了朕的仁慈"** → 系统免责叙事，别再追问结构。
- **"同朝为官，如同乘一船"** → 结构罪：追一人等于追所有人。
- **"上贺表是死，不上贺表或可一生"** → 公开站队，退路已断。
- **"先挂牌署理""先干起来再补文书"** → 既成事实，回退成本被人为抬高。
- **"以改兼赈"** → 听名字像双赢，查契约是土地兼并。
- **"奉旨赈灾"** → 白手套把后台挂到桅杆上，攻击执行者已无效。
- **"他没有顶戴，不是我们的人"** → 组织切割，白手套被抛弃。
- **"小事不糊涂，大事要糊涂"** → 知道调查边界的人，通常活得久。
- **"官做大了便没有书生"** → 位置会重写立场，别用旧标签判断人。
- **"皇上有旨意"却拿不出亲笔** → 口头命令在追责时等于不存在。
- **"我知道了，你好好当差"** → 不追究不等于没记账；克制是权威的另一种形式。

## 快速判断矩阵

遇到一次权力互动，按顺序问四句：

1. **他要什么**：钱、位置、安全、名分，还是时间？
2. **我能给什么**：给得起吗？给了以后拿什么收回？
3. **他怕什么**：失去圣眷、失去证据、失去退路，还是失去体面？
4. **谁承担代价**：如果这项安排出事，第一个被点名的人是谁？

## 三句话总结

- **看权力，先看位置**：座位、门禁、传唤顺序，比话术可靠。
- **看政策，先看账本**：谁出钱、谁得地、谁背锅。
- **看人，先看长期小事**：连续数月的流水，胜过一次壮举。
