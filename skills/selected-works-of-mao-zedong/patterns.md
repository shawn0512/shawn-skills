# 分析模式

以下模式从选集论证中提炼，用于把具体历史判断转成可复用的分析步骤。使用时保留历史语境，不要把当时的敌我结论直接套到无关场景。

## 1. 敌友划分：从经济地位到政治态度

**何时用**：面对一个多派别、多阶级的复杂局势，需要判断谁可能支持、谁可能反对、谁可争取。

**步骤**：
1. 列出各方在生产关系中的位置：占有生产资料与否、受谁剥削、剥削谁。
2. 由经济地位推出其利害：局势变化会使谁受损、谁受益。
3. 观察其在具体斗争中的实际态度，而不是只看口号。
4. 区分“主要敌人”“次要敌人”“可以争取的中间派”“基本力量”。

**原文例证**：《中国社会各阶级的分析》把地主买办、中产阶级、小资产阶级、半无产阶级、无产阶级逐一放到经济结构中定位，再判断其革命态度（第1章）。

**误用**：只按标签（出身、言论）划敌友，不看实际利害；或把中间派当成铁板一块。

## 2. 主要矛盾定位

**何时用**：同时存在多个问题，资源有限，需要决定先解决哪一个。

**步骤**：
1. 列出当前所有矛盾。
2. 找出规定和影响其他矛盾的那一个（主要矛盾）。
3. 找出该矛盾中起主导作用的一方（矛盾的主要方面）。
4. 随局势变化重新判断——主要矛盾会转移（如1935年后民族矛盾上升）。

**原文例证**：《矛盾论》论主要矛盾；《论反对日本帝国主义的策略》根据民族矛盾上升调整阶级政策（第4、7章）。

**误用**：把主要矛盾当成永久标签；或平均用力，什么都抓。

## 3. 具体问题具体分析

**何时用**：有现成理论、别国经验或过去经验，但当前条件不同。

**步骤**：
1. 找出当前矛盾的特殊性：对象、阶段、力量对比、地理与时间条件。
2. 对照一般规律，说明哪些适用、哪些必须修正。
3. 从特殊性中定出具体政策，而不是从原则直接推结论。

**原文例证**：《中国革命战争的战略问题》强调中国革命战争有自己的规律，不能照搬一般战争或苏联经验（第5章）；《反对本本主义》提出“没有调查，没有发言权”（第2章）。

**误用**：把“具体分析”当成不要原则的实用主义；或反过来用原则替代调查。

## 4. 实践—认识—再实践的检验循环

**何时用**：形成了一套判断或方案，需要验证并迭代。

**步骤**：
1. 从实际调查和实践取得感性材料。
2. 经过去粗取精、去伪存真、由此及彼、由表及里，形成概念和判断。
3. 把判断放回实践，看结果是否达到预期。
4. 根据结果修正认识，进入下一轮。

**原文例证**：《实践论》把认识过程概括为两次飞跃：感性到理性、理性到实践（第6章）。

**误用**：停在纸面推演；或只讲“试错”而不做理性总结。

## 5. 以斗争求团结

**何时用**：与盟友/中间力量合作，但对方不断侵蚀你的底线。

**步骤**：
1. 明确共同目标与不可让渡的独立原则。
2. 对越界行为作有理（自卫）、有利（取胜）、有节（适时收手）的斗争。
3. 斗争后仍保留合作框架，不把中间派推向对方。
4. 用“发展进步势力、争取中间势力、孤立顽固势力”安排力量。

**原文例证**：《统一战线中的独立自主问题》《目前抗日统一战线中的策略问题》（第10、12章）。

**误用**：一味退让求团结；或斗争无限升级，破坏联盟。

## 6. 集中优势兵力，各个歼灭

**何时用**：总体处于劣势，但可以在局部形成优势。

**步骤**：
1. 不在全线平均分配力量。
2. 选择孤立、薄弱、便于围歼的一路。
3. 集中绝对或相对优势兵力，四面包围，力求全歼。
4. 打完一路再打下一路，逐步改变总力量对比。

**原文例证**：《集中优势兵力，各个歼灭敌人》《目前形势和我们的任务》十大军事原则（第18章）。

**误用**：把“集中”理解为堆人；或贪多同时开战。

## 7. 战略持久，战役速决

**何时用**：总体实力弱、战争/项目周期长，但又不能拖延每一次具体行动。

**步骤**：
1. 在全局上承认持久，分阶段设定目标（防御—相持—反攻）。
2. 在每一具体战役上追求速决，避免消耗战。
3. 用局部速决的积累逐步改变全局态势。

**原文例证**：《论持久战》三阶段论（第9章）。

**误用**：全局速胜论或全局失败论；局部上又拖成消耗。

## 8. 从群众中来，到群众中去

**何时用**：制定政策、方案，需要既接地气又能执行。

**步骤**：
1. 收集分散的、不系统的群众意见。
2. 集中起来，化为系统的意见和办法。
3. 回到群众中宣传解释，化为群众的行动。
4. 在行动中检验并再次集中。

**原文例证**：《关于领导方法的若干问题》（第13章）。

**误用**：只“到群众中去”发命令，不先“从群众中来”；或只调查不形成决策。

## 9. 解剖麻雀：典型调查

**何时用**：无法全面普查，但需要了解一类情况的真实结构。

**步骤**：
1. 选一个典型单位，深入调查其历史、阶级关系、生产与生活。
2. 把典型搞透，从中找出规律。
3. 再用其他材料验证规律的适用范围。

**原文例证**：《农村调查》的序言和跋、《湖南农民运动考察报告》（第1、2章）。

**误用**：把个案直接当全局结论；或只走马观花。

## 10. 利用矛盾，争取多数，反对少数，各个击破

**何时用**：对手阵营并不统一，己方力量不足。

**步骤**：
1. 分析对手内部各派的不同利害。
2. 拉拢或中立可以争取的部分。
3. 把打击面缩到最小，集中对付当前最顽固的一派。
4. 逐个解决，不树敌过多。

**原文例证**：《论政策》及抗日时期对顽固派的策略（第12章）。

**误用**：把打击面扩大化，逼中间派抱团；或把策略当原则，失去方向。

## 11. 战略上藐视，战术上重视

**何时用**：面对强大对手，既需要信心又需要谨慎。

**步骤**：
1. 在本质和长期上判断对手外强中干，建立必胜信念。
2. 在具体问题和每一次行动上认真对待，研究其强点与弱点。
3. 分别制定长期战略与短期战术，不互相替代。

**原文例证**：《和美国记者安娜·路易斯·斯特朗的谈话》《关于帝国主义和一切反动派是不是真老虎的问题》（第18、22章）。

**误用**：只讲藐视而轻敌；或只讲重视而丧失信心。
