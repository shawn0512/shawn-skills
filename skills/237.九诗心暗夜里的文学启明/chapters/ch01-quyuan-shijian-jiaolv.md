# Chapter 1: 屈原——时间的焦虑

## Core Idea
《离骚》的核心不是忠臣不遇的政治寓言，而是一个站在神话时代与理性时代门槛上的人，第一次经验到环形时间破产、线性时间降临后的存在焦虑；屈原最终拒绝永恒，认领必死的人生。

## Frameworks Introduced
- **环形时间 → 线性时间**
  - When to use: 读《离骚》中草木凋零、美人迟暮、天界求索时。
  - How: 先复原楚地神话时间观（《礼记·月令》、楚帛书、物类相感），再找文本中"时间不再回头"的证据："汩"的流逝、朝/夕压缩、众芳芜秽。
- **神话时代/理性时代门槛**
  - When to use: 解释屈原的巫史身份与《离骚》密集的神灵、香草。
  - How: 三闾大夫即巫史合一；中原"敬鬼神而远之"与《春秋》伦理史观传入，使神话、历史、现实三系统断裂。
- **美人香草之托的双刃**
  - When to use: 判断一处香草是否应读成政治寄托。
  - How: 王逸传统使香草可寄托忠贞，但也把一切花草政治化；先看文本是否提供寓言框架，再决定读法。
- **三界求索结构**
  - When to use: 分析《离骚》后半。
  - How: 人世→天国（帝阍不开）→巫术/历史（灵氛、巫咸）→临睨旧乡；每次求索都失败，失败本身是论点。
- **在永恒门口跌入尘埃**
  - When to use: 读结尾"陟升皇之赫戏兮，忽临睨夫旧乡"。
  - How: 把"回头"读成伦理选择：不接受神灵世界，接受与百草同朽的人类命运。

## Key Concepts
- **环形时间**：自然节律循环，生死如草木荣枯，可"重生"。
- **线性时间**：时间单向流逝，死亡不可逆。
- **内美/修能**：先天血统与天命 vs 后天修养；后者因前者而必要。
- **众芳芜秽**：一切美好之物凋落甚至黑化，是线性时间的核心意象。
- **美人迟暮**：以美人喻理想与生命价值的落空。
- **巫史**：楚国掌管祭祀、谱系、政事的合一角色。
- **摄提格/孟陬/庚寅**：屈原自述寅年寅月寅日出生，证明天命。
- **皇天无亲**：屈原仍信天会赏善罚恶，现实却相反。
- **乱曰**：楚辞结尾的总结性合唱。
- **彭咸**：屈原结尾所效法的投水贤臣。

## Mental Models
- Use "环形时间破产" when 读一切"惜时"诗：先问诗人失去的是时间，还是时间观。
- Think of 《离骚》 as a failed ascent narrative：每次升天都是对永恒的试探，回头才是结论。
- Use "神话—理性门槛" when 读先秦文本：把神灵密度当认识论证据，不当装饰。
- Use "政治寓言是后世追加的读法" when 面对汉代以后的《离骚》解释。

## Anti-patterns
- **把《离骚》全部读成怀王昏庸、忠臣见弃**：会漏掉时间哲学与神话结构。
- **用"众人皆醉我独醒"概括屈原**：该句出自可疑的《渔父》，且与屈原的天命等级思维不合。
- **把香草美人一律政治化**：导致艺术窄化，政治吞噬文学。
- **以为屈原求仙成功**：结尾明确拒绝永恒。

## Worked Example
"朝搴阰之木兰兮，夕揽洲之宿莽"：木兰是初春最早开的花，宿莽是经冬不凋的草。屈原把"朝"与"夕"压进一日，让读者在一日之内经历四季——早晨还是初春，傍晚已到万物凋零的冬天。于是"日月忽其不淹兮，春与秋其代序"不是普通叹老，而是宣布环形时间失效：花谢不会再生。读法：先辨物性（木兰/宿莽），再辨时间跨度（朝/夕），最后看它如何逼出"恐美人之迟暮"。

## Key Takeaways
1. 屈原的焦虑是时间观断裂的焦虑，不只是政治失意。
2. 香草意象首先是时间与价值的意象，政治解释是第二层。
3. 《离骚》的结构是三次求索、三次失败。
4. 结尾"临睨旧乡"是全篇最重要的转折：拒绝永恒，认领必死。
5. 屈原因此成为理性时代人类尊严的原型。
