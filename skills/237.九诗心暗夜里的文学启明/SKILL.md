## Core Frameworks & Mental Models

### 1. 知人论世的三步法（作者的自述方法）
- **通读全集，替换扁平形象**：不靠代表作拼贴诗人；从全集中提取生命历程的复杂细节与内在矛盾。
- **文献校勘、文史互证，服务于"知人"**：还原诗人心灵与现实冲突的现场，而不是堆砌史料。
- **细读文本，解释"转化"**：说明生命在文学的坩埚中经历了怎样的奇异转化。
- Use this when 分析任何诗人：先问"他的全集暴露了哪些矛盾"，再问"哪一次冲突逼出了这个文本"。

### 2. 文本细读的四层检查
1. **声音**：平仄、句长、节奏是否与情绪同构（曹丕"别日何易会日难"以仄声咬牙，下句以平声拖长）。
2. **物性**：意象的自然属性是否被用作论证（木兰早春、宿莽经冬；豆苗最脆弱；蒿草扎根浅）。
3. **结构**：转折、复沓、组诗位置是否改变单句含义（《归园田居》其一必须由后四首重新定义）。
4. **指涉**：文本在回应哪个前代脚本（宋玉悲秋、美人香草、苏李赠答、杜诗）。
- Use this when 读任何一首诗：四层都过一遍，再下判断。

### 3. 时代门槛模型
第一流创作者常出现在两个时代的交界处，比同代人更早感知观念冲突；他们的作品对同时代人显得不可理解。
- 屈原：神话时代/理性时代。
- 曹丕：瘟疫前的乐观/瘟疫后的有限性。
- 杜甫：盛唐/中唐。
- 李清照：北宋/南宋。
- 文天祥、吴梅村：明/清。
- Use this when 读大变局文学：把"风格断裂"解释为"认识论断裂"的证据。

### 4. 光与暗：英雄之光与凡人的微光
- 英雄（文天祥、欧阳修）的光辉可以直接呈现；凡人（李陵、吴梅村）的微光需要更复杂的折射与过滤。
- Use this when 评价"软弱"人物：不要用英雄尺度否定凡人；问他的微光在何处、如何被时代折射。

### 5. 九章母题链（跨章工具）
- **时间的焦虑**（屈原）：环形时间破产，线性时间降临。
- **世界的恶意**（李陵）：天授意 + 人努力 + 人祸阻断 = 存在悲剧；无答案时"挺身承受"。
- **死亡与不朽**（曹丕/陶渊明）：曹丕以文学立碑，陶渊明以"人生如植"重建生活。
- **无希望年代的慰藉**（杜甫）：不靠未来许诺，靠日常、关系、纯粹体验。
- **语言的力量**（欧阳修）：改变语言就改变感受方式与士风；贬谪诗可以不哀怨。
- **离失的史诗**（李清照）：聚—存—散—忆；残忍的减法；冒犯与解放。
- **英雄的省思**（文天祥）：从牺牲到勘破；三重抵抗；苍耳旅程。
- **艳诗的自赎**（吴梅村）：从物化到理解；脆弱的力量；遗貌取神。
- Use this when 遇到跨章主题：先定位母题，再调对应章节的细读。

### 6. 反政治化窄读
- "美人香草之托"使香草可寄托忠贞，但也把一切花草政治化，造成艺术窄化。
- Use this when 面对《离骚》、艳诗、易代诗：先问文本自身是否建立寓言框架；不要默认"美人=君王""艳情=寄托"。

### 7. 组诗/全集整体阅读
- 单篇的乐观可能被同组后篇推翻；单篇的哀怨可能被同卷其他作品修正。
- Use this when 读《归园田居》《拟古》《琴河感旧》《与吴质书》两封：先还原组诗/系列的整体轨迹。

### 8. "诗心"不是格律
- 诗的根本是生命精神的注入；人可以不作诗，但不能没有无伪、专一的诗心。
- Use this when 判断一首诗是否有力量：先看它是否从真实生命问题出发，再看技艺。

## Scope & Limits

本技能仅覆盖该书九章及其引用的作品，不替代原书、注本与学术史。涉及具体字词训释、编年与真伪问题，应回查原书注释与所引文献。书中对《答苏武书》、苏李诗等真伪问题采取"尊重文学传统、保留争议"的态度，使用时不要把它当成定论。
