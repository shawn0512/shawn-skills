# Chapter 35: 第一回合 — 死之警示

## Core Idea
2003 年，乔布斯被诊断出胰腺神经内分泌肿瘤。他拒绝立即手术，尝试素食、草药、针刺等替代疗法，拖延了九个月。这段经历是“现实扭曲力场”在健康领域的失效：意志可以推动产品，但不能替代医学证据。死亡警示最终让他更聚焦，也留下遗憾。

## Frameworks Introduced
1. **死亡警示（Memento Mori）** — 记住自己会死，从而过滤无关紧要的事，聚焦真正重要的。Use when 决策瘫痪/琐事缠身：问“如果只剩一年，我还会做这件事吗”。
2. **力场边界（RDF Boundary in Health）** — 对不可逆的医学事实，意志与信念不能替代手术/证据。Use when 面对健康/安全/法律风险：听专家、看数据、尽快行动。
3. **拖延的复利（Cost of Delay）** — 九个月的替代疗法可能增加了后续治疗难度。Use when 面对坏消息：拖延的“心理舒适”有真实代价。
4. **聚焦的紧迫感（Urgency from Mortality）** — 病后乔布斯更激进地推进 iPhone/iPad。Use when 组织惰性：用时间有限性打破拖延。

## Key Concepts
- **胰腺神经内分泌肿瘤**：罕见、生长较慢，早期可手术。
- **2003 年 10 月**：CAT 扫描发现阴影。
- **替代疗法**：素食、果汁、针刺、草药、灵媒。
- **2004 年 7 月**：手术切除肿瘤。
- **斯坦福演讲**：“记住你即将死去”是重要工具。
- **遗憾**：乔布斯后来承认应该更早手术。

## Mental Models
- **Use 死亡警示 when 优先级混乱**：用有限时间过滤噪音。
- **Use 专家优先 when 健康/安全风险**：意志不能改变病理。
- **Use 延迟成本 when 拖延坏消息**：把“现在处理”与“以后处理”的代价写出来。
- **Use 紧迫感 when 组织拖延**：把“总有一天”改成“现在”。

## Anti-patterns
- 用“信念/正能量”替代医学治疗。
- 把忙碌当健康；忽视身体信号。
- 把死亡警示当口号，而不真正改变优先级。

## Worked Example
医生在 CAT 扫描中发现胰腺阴影，建议进一步检查。乔布斯最初拒绝，几天后才被说服。活检显示是生长较慢的神经内分泌肿瘤，医生甚至高兴得哭了——还有手术机会。但乔布斯拒绝手术，尝试素食、果汁、针刺、草药，甚至灵媒。九个月后才手术。后来他说：“我当时真的不想让他们把我的身体切开。”这个案例说明：即使最擅长扭曲现实的人，也无法扭曲病理。

## Key Takeaways
1. 意志可以改变团队信念，不能改变医学事实。
2. 面对坏消息，拖延有真实代价。
3. 死亡警示的价值在于过滤噪音、聚焦重要。
4. 专家意见在不可逆风险面前必须优先。
5. 健康是领导力的底层基础设施。
