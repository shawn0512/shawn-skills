# Chapter 26: 设计原则 — 乔布斯和艾夫的工作室

## Core Idea
乔布斯与乔尼·艾夫的合作，是“设计不是外观，而是产品如何工作”的最佳实践。两人在工作室里通过模型、材料、手感反复推演，把工程、美学与制造绑在一起。设计不是最后一道工序，而是产品定义本身。

## Frameworks Introduced
1. **设计即工作方式（Design Is How It Works）** — 不只是外观，而是从材料、结构、交互到制造的整体。Use when 评审设计：问“它如何被使用、制造、维修”，而不只是“它看起来怎样”。
2. **模型驱动决策（Prototype-Driven Decisions）** — 用泡沫模型、3D 打印、实物手感来讨论，而不是抽象图纸。Use when 设计分歧：先做可触摸的原型，让身体反应参与决策。
3. **直接协作（Direct Collaboration）** — 乔布斯绕过层级，直接与艾夫团队工作。Use when 创新被流程拖慢：建立高层与核心团队的直连。
4. **材料诚实（Material Honesty）** — 材料要表达其本性：铝的凉、玻璃的通透、塑料的温润。Use when 选材：不要用假材料伪装另一种材料。

## Key Concepts
- **乔尼·艾夫**：苹果设计主管，英国人，工匠家庭出身。
- **设计工作室**：布满模型、材料、机器的“神圣空间”。
- **“设计是产品如何工作”**：乔布斯的核心定义。
- **端到端整合**：设计、工程、制造必须一起决策。
- **模型文化**：用实物而非幻灯片讨论。
- **艾夫的工匠伦理**：无法忍受“草率的态度”。

## Mental Models
- **Use 整体设计 when 产品由多部件组成**：任何单点美学都必须与结构、制造、交互兼容。
- **Use 原型 when 讨论抽象**：让手去感受，比让嘴去争论更快达成共识。
- **Use 直连 when 创新受阻**：让决策者直接接触核心团队，减少信息损耗。
- **Use 材料诚实 when 选材**：材料的触感、重量、老化方式都是体验的一部分。

## Anti-patterns
- 把设计当“美化”，在工程完成后才介入。
- 用效果图代替实物，忽视手感、重量、装配。
- 让层层审批稀释设计决策。

## Worked Example
iMac 的外壳：艾夫想做半透明塑料，让用户看到内部；乔布斯要求内部电路板也整齐。两人一起在工作室里看模型、调颜色、讨论提手。工程部门提出 38 个不能做提手的理由，乔布斯说“我就是要做”，最终落地。这个案例说明：设计决策是美学、工程、制造的联合决策，不是设计师一个人的灵感。

## Key Takeaways
1. 设计是产品定义，不是最后的美化。
2. 实物原型能加速高质量决策。
3. 高层与核心设计团队的直连，能保护创新。
4. 材料与工艺必须诚实，不能伪装。
5. 设计师必须理解工程与制造，否则设计无法落地。
