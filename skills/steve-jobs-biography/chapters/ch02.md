# Chapter 2: 奇特的一对 — 两个史蒂夫

## Core Idea
乔布斯与沃兹尼亚克是“愿景 + 工程”的经典互补组合：沃兹能造出优雅的机器，乔布斯知道如何把它变成产品、生意和故事。两人的差异不是缺陷，而是分工的基础；但价值观差异也为后来的股权与忠诚冲突埋下伏笔。

## Frameworks Introduced
1. **互补合伙人模型（Complementary Co-founder Model）** — 一人负责技术可行性，一人负责产品化、营销与资源整合。Use when 创业团队需要同时解决“能不能做”和“为什么有人买”。
2. **蓝盒子启示：技术 + 胆量 = 杠杆** — 沃兹做出盗打电话的蓝盒子，乔布斯负责把它卖出去。两人第一次验证：好技术若没有商业化，只是玩具。
3. **极客与嬉皮士的融合** — 湾区反文化（禅、迷幻药、音乐）与工程文化结合，产生“为个人赋权”的个人电脑理念。

## Key Concepts
- **沃兹的纯粹工程伦理**：绝不撒谎、厌恶商业野心、追求技术优雅。
- **乔布斯的商业直觉**：识别价值、定价、包装、讲述。
- **蓝盒子**：非法但重要的早期创业演练。
- **惠普模式 vs 车库模式**：大公司流程 vs 小团队自由。
- **互补而非相同**：招聘时寻找能补足短板的人，而非复制自己。

## Mental Models
- **Use 互补合伙人 when 选择联合创始人**：先问“他能否做我做不到的事”，而不是“他是否像我”。
- **Use 技术商业化 when 手握好发明**：技术只完成一半，另一半是让普通人理解并愿意付费。
- **Use 价值观对齐检查 when 分配股权/角色**：能力互补不等于价值观一致；提前谈清钱与控制权。

## Anti-patterns
- 把合伙人当执行工具，而非独立判断者。
- 用“我们是最好的朋友”回避股权、角色、退出机制的谈判。
- 只崇拜技术，忽略把技术送到用户手中的最后一公里。

## Worked Example
蓝盒子：沃兹设计出能免费打长途电话的装置，成本不高；乔布斯坚持把它包装成产品出售，并承担风险。两人赚到第一笔钱，也第一次体会“技术可以改变普通人的行为”。这成为 Apple I 的原型经验：沃兹负责“能做”，乔布斯负责“该做、怎么做、卖给谁”。

## Key Takeaways
1. 最强搭档往往不是最像你的人，而是能补全你盲区的人。
2. 工程师文化追求正确，创业文化追求被采用；两者需要翻译者。
3. 早期合作要尽快明确股权与控制权，友谊不能替代契约。
4. 反文化不是商业的对立面；它可以成为产品差异化的来源。
5. 乔布斯的魅力来自“把不可能讲得像已经发生”，沃兹的价值在于把它变成现实。
