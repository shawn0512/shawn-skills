# Chapter 33: 皮克斯的朋友 — ……当然还有敌人

## Core Idea
皮克斯的成功让乔布斯获得谈判资本，也暴露了他的战斗性：与迪士尼/卡曾伯格的冲突、与艾斯纳的对抗，最终以迪士尼收购皮克斯、乔布斯成为最大股东并进入迪士尼董事会收场。创意公司的核心资产是人才与信任，而不是合同条款。

## Frameworks Introduced
1. **创意文化保护（Protect Creative Culture）** — 乔布斯克制控制欲，让拉塞特团队保持创作自由。Use when 创始人收购创意公司：保护其文化，而不是同化。
2. **谈判杠杆转移（Negotiation Leverage Shift）** — 《玩具总动员》成功后，皮克斯从弱势方变成强势方，要求更公平的分成。Use when 合作条款基于旧实力：成功后可重新谈判。
3. **冲突升级管理（Conflict Escalation）** — 乔布斯与卡曾伯格/艾斯纳的冲突从创意纠纷升级为公开战争。Use when 合作破裂：区分“利益冲突”与“人身攻击”，保留未来合作可能。
4. **收购作为终局（Acquisition as Endgame）** — 迪士尼 74 亿美元收购皮克斯，乔布斯成为最大个人股东。Use when 合作关系无法修复：用资本交易重新定义关系。

## Key Concepts
- **《虫虫危机》 vs 《小蚁雄兵》**：创意归属争议。
- **迈克尔·艾斯纳**：迪士尼 CEO，与乔布斯长期对抗。
- **罗伯特·艾格**：艾斯纳继任者，推动收购皮克斯。
- **74 亿美元收购**：2006 年，皮克斯并入迪士尼。
- **乔布斯进入迪士尼董事会**：成为最大个人股东。
- **创意信任**：拉塞特与卡特穆尔的文化是核心资产。

## Mental Models
- **Use 文化保护 when 收购创意公司**：保留团队、创作权、失败空间。
- **Use 杠杆重估 when 合作成功**：定期重新谈判，让条款匹配新实力。
- **Use 冲突分层 when 关系破裂**：把人和事分开，避免烧桥。
- **Use 资本终局 when 合作无法修复**：用收购/退出重新定义关系。

## Anti-patterns
- 收购后强行注入母公司文化，赶走创意人才。
- 把创意纠纷升级为人身攻击，破坏长期合作。
- 在弱势时签下永久不平等条款，成功后无法调整。

## Worked Example
卡曾伯格离开迪士尼后，皮克斯认为他窃取了《虫虫危机》的创意并制作《小蚁雄兵》。乔布斯公开斥责卡曾伯格“骗子”；卡曾伯格则称皮克斯早有预谋。真相更复杂：拉塞特曾向卡曾伯格透露创意。冲突持续多年。后来艾格接任迪士尼 CEO，主动修复关系，最终以 74 亿美元收购皮克斯。乔布斯从“敌人”变成迪士尼最大股东。这个案例说明：创意行业的冲突往往源于信任破裂，而资本可以重新安排关系。

## Key Takeaways
1. 创意公司的核心资产是人才、信任与文化。
2. 成功会改变谈判杠杆，条款应随之更新。
3. 冲突要分层：利益可以谈，人身攻击会烧桥。
4. 收购可以是关系的终局，也可以是新合作的开始。
5. 保护创作自由，比控制细节更能产生好作品。
