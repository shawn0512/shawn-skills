# Chapter 39: 新的战斗 — 昔日重现

## Core Idea
安卓的崛起让乔布斯再次面对“开放 vs 封闭”的战争。他认为谷歌背叛了苹果——利用董事会席位获取信息，复制 iPhone 的多点触控与界面。乔布斯的反应是“核战争”：起诉 HTC/安卓，拒绝和解。这一章展示价值观冲突如何演变为专利战与生态竞争。

## Frameworks Introduced
1. **开放 vs 封闭的价值观冲突（Open vs Closed Values）** — 谷歌把安卓作为开放平台，苹果坚持端到端控制。Use when 平台竞争：明确你的模式依赖什么，别在对方战场上打。
2. **背叛叙事（Betrayal Narrative）** — 乔布斯把谷歌的行为定义为“偷窃”，而非“竞争”。Use when 合作伙伴进入你的领域：区分法律事实与情感叙事，避免决策被愤怒主导。
3. **专利作为竞争武器（Patents as Weapons）** — 苹果起诉 HTC，连带安卓，主张多点触控等专利。Use when 技术被复制：用法律手段保护差异化，但注意成本与反诉。
4. **“核战争”式承诺（Thermonuclear Commitment）** — 乔布斯说愿意花光 400 亿美元纠正错误。Use when 核心价值被侵犯：表达决心可以凝聚团队，但也可能锁死退路。

## Key Concepts
- **安卓**：谷歌的开放移动操作系统。
- **埃里克·施密特**：谷歌 CEO，曾为苹果董事。
- **HTC 诉讼**：2010 年，苹果起诉 HTC 侵犯 20 项专利。
- **“不作恶”**：谷歌口号，乔布斯斥为“扯淡”。
- **多点触控/滑动解锁**：争议专利。
- **开放生态的规模 vs 封闭生态的体验**。

## Mental Models
- **Use 模式自知 when 平台竞争**：清楚你的优势来自整合还是规模，不要在对方优势上硬拼。
- **Use 事实/叙事分离 when 合作破裂**：先确认法律与合同事实，再处理情绪。
- **Use 专利武器 when 技术被复制**：评估诉讼成本、反诉风险、市场影响。
- **Use 决心表达 when 团队动摇**：强硬姿态能凝聚，但要保留谈判空间。

## Anti-patterns
- 被愤怒驱动，拒绝一切和解，陷入长期诉讼消耗。
- 把“开放”当道德高地，忽视体验碎片化。
- 把合作伙伴的竞争行为全部解释为“背叛”，失去学习机会。

## Worked Example
2010 年 iPad 发布后几天，乔布斯在员工大会上痛斥谷歌：“我们没有涉足搜索，他们却进入手机业务。他们想要终结 iPhone，我们不会让他们得逞。”随后苹果起诉 HTC，称安卓侵犯 20 项专利。乔布斯对作者说：“我要摧毁安卓，因为它是偷来的产品。我愿意发动核战争。”施密特提议喝咖啡和解，乔布斯拒绝：“我不想要你们的钱，我只要你们停止使用我们的创意。”这场战争持续多年，改变了移动生态的竞争格局。

## Key Takeaways
1. 平台竞争本质是价值观与商业模式之争。
2. 愤怒可以凝聚团队，也会锁死战略选项。
3. 专利战是竞争工具，不是道德审判。
4. 开放与封闭各有代价，关键是匹配自身能力。
5. 合作破裂时，先处理事实，再处理情绪。
