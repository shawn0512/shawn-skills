# Chapter 22: 玩具总动员 — 巴斯和胡迪救场

## Core Idea
皮克斯与迪士尼的合作，是“弱势方用独特能力换取入场券”的案例。乔布斯没有技术授权可卖，就用皮克斯的动画能力换来电影合约；他接受了不平等的条款，因为只有先上场，才有机会证明价值。《玩具总动员》的成功让皮克斯从濒死公司变成 IPO 明星。

## Frameworks Introduced
1. **用能力换入场券（Capability-for-Access）** — 资源不足时，用对方无法替代的能力换取合作机会，接受短期不平等条款。Use when 弱势方谈判：先获得“上桌权”，再谈长期分成。
2. **产品有灵魂（Products with Souls）** — 拉塞特与乔布斯相信：物品的使命决定其情感。Use when 做内容/产品：先定义“它为何存在”，再设计功能。
3. **创意与商业分工（Creative-Business Split）** — 拉塞特负责故事，乔布斯负责融资、谈判、发行。Use when 创意公司：让专业的人做专业的事。
4. **IPO 作为杠杆（IPO as Leverage）** — 《玩具总动员》成功后，皮克斯上市，乔布斯获得谈判资本。Use when 与强势伙伴合作：用资本市场增强议价能力。

## Key Concepts
- **杰弗里·卡曾伯格**：迪士尼动画负责人，强势谈判者。
- **迪士尼协议**：迪士尼拥有影片/角色版权与创作控制，皮克斯分成约 12.5%。
- **《玩具总动员》**：1995 年上映，首部全电脑动画长片。
- **角色 IP**：胡迪、巴斯光年，可跨作品复用。
- **皮克斯 IPO**：1995 年 11 月，乔布斯成为亿万富翁。
- **“飞向太空，宇宙无限”**：巴斯光年的口号，象征野心。

## Mental Models
- **Use 能力换入场 when 弱势谈判**：先问“我有什么是对方无法轻易替代的”，用它换机会。
- **Use 灵魂定义 when 做产品/内容**：先写“它的使命是什么”，再写功能与情节。
- **Use 分工 when 创意+商业并存**：明确谁对故事有最终决定权，谁对交易有最终决定权。
- **Use IPO杠杆 when 合作条款不利**：用独立融资/上市增加退出选项。

## Anti-patterns
- 在弱势时坚持“平等条款”，结果失去上场机会。
- 让商业方干预创作，做出“安全但平庸”的内容。
- 成功后立即报复性谈判，破坏长期关系（乔布斯后来与迪士尼的冲突）。

## Worked Example
卡曾伯格问乔布斯：“迪士尼对皮克斯满意吗？”乔布斯说满意。又问：“那皮克斯对迪士尼满意吗？”卡曾伯格以为满意。乔布斯说：“错，我们不满意。我们想跟你们合作一部电影。”卡曾伯格被这种直接打动，促成了合作。谈判中乔布斯想要角色所有权，卡曾伯格说“那就不用谈了”，乔布斯让步。先上场，后用《玩具总动员》的成功改变谈判地位。

## Key Takeaways
1. 弱势方的首要目标是获得入场资格，而不是立即拿到最优条款。
2. 独特能力是最硬的谈判货币。
3. 创意与商业需要明确分工与互信。
4. 产品的情感基础来自“它为何存在”。
5. 成功会改变谈判结构，但也会放大人性冲突。
