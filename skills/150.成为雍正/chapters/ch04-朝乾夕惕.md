# 第四章 朝乾夕惕：雍正帝继位后的日子

## Core Idea
雍正以45岁"大龄皇帝"的身份，在13年内推行了8项制度改革，将康熙朝的烂摊子改造成税收清晰、治理高效、社会安定的超强国家机器。本章展现了雍正作为制度设计师的卓越能力与雷霆手段。

## Frameworks Introduced
- **三板斧改革法**: 追缴亏空（整顿风气）→ 密折专奏（加强控制）→ 火耗归公（制度化反腐）
- **分类追缴策略**: 因公事挪用/被上司勒索→允许三年内还清；官员自己贪污→立刻抓起来免职
- **抄家连坐制**: 官员办公室和老家资产一并查封；自杀的，抓全家；转移资产给亲友的，查亲友

## Key Concepts
- **会考府**: 雍正元年正月成立，清朝版审计署，由怡亲王亲自挂帅，一年查出户部亏空259万2957两6钱3分1厘
- **密折专奏**: 康熙朝40年仅200人有资格，雍正朝13年超过1300人，实现自己对官场的高度控制
- **火耗归公**: 将"火耗"合法化，维持低税率，收归国有，再分拨给各级衙门作办公经费和官员俸禄（养廉银）
- **摊丁入亩**: 取消丁税，分摊到地税中，减轻穷人负担，确保社会安定
- **官绅一体当差，一体纳粮**: 动权贵集团蛋糕的深水区改革

## Mental Models
- 使用"不是分赃，是玩命"理解雍正改革的本质：动的就是权贵集团的利益
- 将"抄家皇帝"的骂名视为改革的必要代价：朕抄错了，顶多祸害一家；放过他们，会祸害一方百姓
- 理解"8岁登基之君"的自信：雍正凭借多年办差经验，对官场花花肠子非常熟悉

## Anti-patterns
- **革职留任**: 有人建议让贪官"革职留任"戴罪立功，雍正直接驳回：这等于纵容他继续勒索百姓
- **百姓代补**: 有人拿"万民伞"和"请愿书"求情，雍正非但不准，还派人调查是否有黑恶势力强迫百姓
- **加派之名**: 康熙担心"火耗归公"会背上"加派百姓"的恶名，雍正则不怕挨骂

## Key Takeaways
1. 改革必须有系统性的制度设计，不能只靠运动式治理
2. 追缴亏空的前提是不能让官员勒索百姓，影响社会安定
3. 密折制度是实现信息控制的有效手段，但需要皇帝亲自投入巨大精力
4. 养廉银制度一举三得：保证清官开支、避免百姓被盘剥、实现财政精细化管理
5. 改革者必须有承受骂名的心理准备：虱子多了不咬，债多了不愁

## Worked Example
雍正追缴地方亏空的操作流程：
1. 第一步：分类——因公事挪用/被上司勒索→允许三年内还清；贪污→立刻免职
2. 第二步：抓人——从中央派侍郎（一个管财政查账，一个管司法抓人），带40多个候补官员组成办案团队
3. 第三步：顶缺——一旦查到贪污，就地逮捕，从候补官员中挑人原地顶替
4. 第四步：抄家——办公室和老家资产一并查封；自杀的，抓全家；转移资产的，查亲友

结果：雍正元年国库存银2361万两，四年后涨到4741万两，直接翻倍。
